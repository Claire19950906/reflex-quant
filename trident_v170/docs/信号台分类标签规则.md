# 信号台分类标签规则（real time event bus）

> 实时信号台每条新闻左上角的分类标签（加密 / 黄金 / 原油 / 美股 / 宏观 / 其他），
> 以及顶部 tab 的分类过滤，共用同一套判定逻辑。本文档说明完整判定链。

---

## 一、六个分类

| key | 标签 | 覆盖内容 |
|---|---|---|
| `CRYPTO` | 加密 | BTC/ETH/SOL 等加密资产相关 |
| `GOLD` | 黄金 | XAU 金价/贵金属 |
| `OIL` | 原油 | WTI 油价/能源 |
| `STOCK` | 美股 | 13 只可交易美股（NVDA/TSLA/AAPL/MSTR/MSFT/AMZN/GOOGL/COIN/PLTR/META/SMCI/MARA/RIOT）|
| `MACRO` | 宏观 | 央行/利率/CPI/非农/美债等宏观传导 |
| `OTHER` | 其他 | 无法归类的新闻 |

前端定义：`frontend/components/quant/event-bus.tsx` → `EVENT_CATEGORIES`。

---

## 二、判定优先级（由高到低）

分类**不是单一规则**，而是三层判定的流水线。
前端函数：`eventCategory(event)`（event-bus.tsx）。

```
① source 是美股新闻源（yahoo_stock / finnhub）？
   → 判「美股」STOCK                    ← 最高优先（源级归属）
   ↓ 否
② AI 分析对象 target_asset 命中映射？
   XAU / GOLD           → GOLD 黄金
   WTI / CL / OIL       → OIL 原油
   13 只美股清单之一    → STOCK 美股
   BTC / ETH / SOL      → CRYPTO 加密
   ↓ 否
③ AI 的 market_category（后端已修正过）？
   CRYPTO/GOLD/OIL/MACRO（非 OTHER/ALL）→ 直接用
   ↓ 否
④ 新闻原文英文关键词兜底？
   bitcoin|ethereum|crypto|binance|stablecoin      → CRYPTO
   gold|bullion                                     → GOLD
   crude|oil|opec|hormuz|energy price              → OIL
   central bank|inflation|treasury|bond|yield|
     interest rate|pmi|gdp|tariff                  → MACRO
   ↓ 都不中
⑤ OTHER 其他
```

### 关键设计：target_asset 优先于 market_category

前端判定第 ② 步优先用 `target_asset`（AI 实际分析/交易的对象）而不是
`market_category`（AI 随口报的类别）——保证**标签与 AI 分析内容永远一致**。
这是修复"标签写原油、分析内容却是 BTC"问题后确立的规则。

### 特例：美股源级硬判

第 ① 步按 source 直接判 STOCK，先于 target_asset——
因为美股新闻源即使 AI 把 target 标为 NONE（如清单外的 INTC 不可交易，
只能分析不能下单），标签也应显示"美股"而非"其他"。

---

## 三、字段来源：AI 分析产出

`target_asset` 与 `market_category` 是 **AI 模型分析每条新闻时输出的 JSON 字段**
（六段推演后的结构化结论），prompt 定义见 `backend/src_python/engine/ai_worker.py`：

```json
"market_category": "<CRYPTO|GOLD|OIL|MACRO|OTHER>",
"target_asset":    "<BTC|ETH|XAU|WTI|...股票代码|NONE>",
```

---

## 四、后端一致性强制（防 AI 乱报）

### 4.1 Prompt 铁律（ai_worker.py）

```
market_category 必须与 target_asset 对应：
  GOLD ↔ XAU、OIL ↔ WTI、CRYPTO ↔ BTC/ETH/SOL；
  宁可报 OTHER 也不输出"分类与分析对象不一致"的矛盾

典型归类指引：
  地缘冲突/战争/制裁           → GOLD + XAU
  央行利率/CPI/流动性政策      → CRYPTO + BTC（宏观通过利率预期影响加密）
  能源/OPEC/中东产油/原油库存  → OIL + WTI
  加密行业自身(ETF/监管/技术)  → CRYPTO + BTC
  无法归类                     → OTHER + NONE
  美股公司新闻(带 [美股行情])  → target_asset=对应股票代码
```

### 4.2 后端兜底修正（_reconcile_category_asset）

即使 AI 报错，后端落库前也强制纠正（`target_asset` → `_ASSET_TO_CATEGORY` 映射表）：

```
例：AI 报 market_category=OIL 但 target_asset=BTC
  → 后端修正 market_category = CRYPTO
  → 日志：[CATFIX] market_category=OIL 与 target_asset=BTC 不一致 → 修正为 CRYPTO
```

规则细节：
- 以 `target_asset` 为准修正 `market_category`
- `MACRO` / `OTHER` 保留模型判断（宏观传导类不强行映射）
- `target_asset = NONE` 不改分类

---

## 五、完整数据流

```
新闻入库
  → AI worker 六段分析
  → 输出 market_category + target_asset（JSON）
  → 后端 _reconcile_category_asset 修正一致性 → [CATFIX] 日志
  → 落库 ai_decisions
  → 前端 eventCategory() 三级判定
      (源级美股 → target_asset → market_category → 文本关键词)
  → 左上角标签显示 + 顶部 tab 按同函数过滤
```
