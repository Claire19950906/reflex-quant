> 本文档详细到"判定公式 + 参数 + 影响"，供决策后按阶段实施

# 一、P1：止损体系（需求 3，第一优先）

**改动核心：`engine/forward.py`（持仓跟踪结算）+ 参数表**

## 1.1 现状（要保留的）

```
每 5s 轮询 → 更新 max_price/min_price → 到期结算（holding_horizon_minutes 或默认 120 分钟）
→ verdict 决策树（MFE/MAE vs IMPACT_THRESHOLD → WIN/LOSS/HOLD）
```

## 1.2 ATR 初始止损（3a）

**目的**：入场就带止损，亏损单不裸奔；距离按波动自适应（高波动品种给宽，不会被正常波动扫掉）。

**判定逻辑**（每轮）：
```
BUY:  stop_price = entry × (1 − stop_loss_atr_mult × atr_pct / 100)
SELL: stop_price = entry × (1 + stop_loss_atr_mult × atr_pct / 100)
若 price ≤ stop_price（BUY）→ 触发，按当前价结算
```

- `atr_pct`：来自 decision_context 行情快照的 `stats_7d.atr_pct`（决策时已记录）
- **注意**：forward 当前查询没取 decision_context，需在 SQL 里加

**参数**：`stop_loss_atr_mult` = 2.0（范围 0.5~5，后台可调）
- 默认 2.0×ATR：XAU（atr 约 1%）→ 止损约 2%；BTC（atr 约 3-5%）→ 止损约 6-10%，不会被日常波动扫掉

**兼容**：默认开启；旧持仓（decision_context 无 atr_pct）→ 跳过初始止损，只走其他层

## 1.3 保本止损（3b）

**目的**：先保本再让利润奔跑——这是"抓住一波行情"的前提（最差结果是平局，不是亏损）。

**判定逻辑**（每轮）：
```
MFE_pct = (max_price − entry) / entry × 100          # BUY
若 MFE_pct ≥ break_even_pct → 止损下限提升到 entry（保本）
     当前止损 = max(初始止损, entry)
```

**参数**：`break_even_pct` = 0.5（%，范围 0.1~5，后台可调）

**兼容**：默认开启；对当前逻辑影响 = 仅提升止损位，其他不变

## 1.4 分级移动止损（3c，替代固定回撤率）

**目的**：盈利越深、回撤容忍越小（锁住利润），替代单一 `trailing_callback_rate`。

**判定逻辑**（每轮，基于 max_price/min_price）：
```
盈利档 = MFE_pct（BUY）
tier 匹配：盈利 ≥ 1%  → 回撤容忍 50%
           盈利 ≥ 2%  → 回撤容忍 40%
           盈利 ≥ 3%  → 回撤容忍 30%
BUY:  stop_price = max_price × (1 − 回撤容忍/100)
SELL: stop_price = min_price × (1 + 回撤容忍/100)
若 price ≤ stop_price → 触发，按当前价结算
```

**参数**：`trail_tiers` JSON（后台可调）：
```json
[{"profit_pct": 1.0, "drawdown_pct": 50},
 {"profit_pct": 2.0, "drawdown_pct": 40},
 {"profit_pct": 3.0, "drawdown_pct": 30}]
```
- 默认档位：盈利<1% 时不触发移动止损（只靠初始/保本）
- **兼容**：若策略自带 `trailing_callback_rate` 仍优先（旧策略行为不变）；新参数为空时行为=原逻辑

# 二、P2：出场增强（需求 3 第二层 + 需求 2 的"锁利润"）

## 2.1 分级止盈（3d）— 真·部分止盈（50% / 30% / 20%）

**目的**：脉冲式新闻（CPI/突发利空）行情快速兑现，先落袋一半；保留部分仓位让趋势跑完。

**判定逻辑**：
```
历史均值 = 已结算的同 (asset × event_strength) 的 mean(MFE_pct)   # 如 XAU 强催化 ≈ 1.2%
目标价1  = entry × (1 ± tp1_mult × 历史均值)    # tp1_mult=0.6 → 0.72%
目标价2  = entry × (1 ± tp2_mult × 历史均值)    # tp2_mult=1.0 → 1.2%

触及目标价1 → 平仓 50%（记录 partial），剩余 50% 继续持仓
触及目标价2 → 再平仓 30%（累计 80%），剩余 20% 继续
剩余 20% → 交给移动止损 / 到期兜底（吃到趋势尾巴）
最终 pnl = 已平部分按各自平仓价 + 剩余部分按结算价（加权平均）
```

**技术实现（不拆行）**：
- `ai_decisions` 加 3 个字段（migrate 幂等，不动主键/唯一约束）：
  - `partial_exit_price`（上一档平仓价）
  - `partial_exit_ratio`（已平比例 0 / 0.5 / 0.8）
  - `partial_pnl_pct`（已实现利润累计）
- forward 每轮判断：未到 ratio 上限且价格触目标 → UPDATE 记录部分平仓；最终结算时 pnl = 加权（已平×平仓价 + 剩余×结算价）
- 持仓展示（前端）可显示"已平 50%"状态

**参数**：`tp1_mult`=0.6、`tp2_mult`=1.0（历史 MFE 系数，0.3~1.5）、`tp1_ratio`=0.5、`tp2_ratio`=0.3（后台可调）
- 历史均值查询：`SELECT asset, event_strength, AVG(mfe_pct) FROM ai_decisions WHERE settled=1 GROUP BY 1,2`（样本≥5）

**兼容**：默认开启；样本不足（<5）→ 跳过止盈，只走移动止损；不带字段的旧持仓不影响

## 2.2 市场反应窗口（3e）

**目的**：新闻驱动行情如果"没反应"，说明判断错了/市场已定价——不干等到期。

**判定逻辑**：
```
入场后 elapsed ≤ exit_window_minutes（60）且 MFE_pct < window_min_mfe（0.3%）
→ 新闻没驱动行情，按当前价提前离场（verdict 走原决策树，大概率 HOLD）
```

**参数**：`exit_window_minutes`=60、`window_min_mfe`=0.3（%，后台可调）

**风险**：可能误杀"慢反应"的宏观趋势类新闻（如 FRED 趋势事件本就 1-3d 周期）——**建议对 event_strength=high 或 expected_horizon ∈ (1-3d, 1w+) 的持仓豁免此层**（默认豁免，参数可调）

## 2.3 冲高回落止盈（3f）

**目的**：快速冲高说明主升段已走，回落超比例说明动能衰竭——止盈走人。

**判定逻辑**：
```
fast_peak：elapsed ≤ 30 分钟 且 MFE ≥ fast_peak_pct（0.5%）
且回落：当前价距峰值回撤 ≥ pullback_ratio（50%）
→ 止盈平仓，verdict=WIN
```

**参数**：`fast_peak_pct`=0.5、`fast_peak_minutes`=30、`pullback_ratio`=50（%，后台可调）

# 三、P3：买入/卖出质量优化（需求 2 第二层）

## 3.1 BUY 准入加严 + 方向不对称门槛（2a/2d）

**目的**：做多胜率 53.4% < 做空 56.3%，买入需要更严格。

**判定逻辑**（decision_guard.evaluate_decision，参数化）：
```
现: final_score ≥ +0.3 → BUY   |  ≤ −0.3 → SELL
改: final_score ≥ buy_min_score（0.4）→ BUY
    final_score ≤ −sell_min_score（0.3）→ SELL     # 做空门槛略低，倾向做空
中间 → HOLD
```

**参数**：`buy_min_score`=0.4、`sell_min_score`=0.3（范围 0.2~0.8，后台可调）

**兼容**：默认开启后 BUY 会变少（更精）；想要旧行为调回 0.3/0.3

## 3.2 新鲜度分级（2b）

**目的**：比"硬门槛 45 分钟"更平滑——越新的新闻信号越强。

**判定逻辑**（ai_worker 打分后按新闻年龄加权）：
```
0~15 分钟 → 权重 1.0
15~30     → 权重 0.85
30~45     → 权重 0.70
>45       → 不建仓（沿用现有硬门槛）
score_final = score_llm × 权重
```

**参数**：档位表 JSON（后台可调，默认如上）
**兼容**：默认开启；关闭则回到纯硬门槛

## 3.3 品种×方向胜率注入（2c）

**目的**：让 AI 知道"BTC 做多 51% vs XAU 做空 62%"这种组合差异，低胜率组合自动降置信。

**实现**：参考信号注入扩展——按 (asset, direction) 统计胜率，注入 prompt 的 `[Reference Signals]`（现有机制扩展，工作量小）

# 四、P4：AI 反思深化（需求 1）

## 4.1 单笔实时反思（1a）
- 每笔结算后立即调 LLM 生成单笔归因（复用 17/10 框架 + 单笔上下文）
- 写入 review_insights 候选表（带 decision_id 关联），日复盘时汇总去重
- 收益：反思频率从"每天"到"每笔"，迭代快几十倍
- **成本**：每笔一次 LLM 调用（约 1-2 秒/笔，可接受）

## 4.2 经验命中验证（1b）
- ai_decisions 加 `insight_hit_ids` 字段：建仓时记录命中的生效经验 id
- 结算后统计每条经验的遵守率 + 对应胜率
- 只回灌"被遵守且有效"的经验（自动停用"遵守但无效"和"不遵守但有效"的经验并提示）

# 五、数据流示例（XAU 利空新闻 → 出场全流程）

```
[新闻] 美债收益率急升（利空黄金）→ AI 分析（新鲜度 10 分钟，权重×1.0）
→ SELL XAU，score=-0.6（≤−0.3 通过，做空门槛低）
→ 闸门通过 → 建仓 @ 4590
持仓中（每 5s）：
  ├ 初始止损: entry×1.02 = 4681.8（2×ATR）→ 保护下限
  ├ 价格跌到 4570（MFE 0.44%）→ 保本止损触发 → 止损位=4590
  ├ 继续跌到 4550（MFE 0.87%）→ 分级移动止损：盈利≥1%档？(0.87<1) 未到
  ├ 冲高回落检测：30 分钟内 MFE 0.44% < 0.5% → 未触发
  ├ 市场反应窗口：60 分钟内 MFE≥0.3% → 不触发（有反应）
  ├ 止盈检测：历史 XAU 强催化 mean MFE=1.2% → 目标1=4590×0.9928=4557、目标2=4590×0.988=4535
  │   价格触及 4557 → 平仓 50%（记录 partial）；触及 4535 → 再平 30%
  │   剩余 20% 交给移动止损/到期
  └ 若都没触发 → 120 分钟到期结算（pnl=已平部分+剩余部分加权）
```

# 八、风险与权衡

| 风险 | 缓解 |
|---|---|
| ATR 止损过紧/过松（atr_pct 口径偏差）| 默认 2.0 宽松起步；后台可调；观察一周调整 |
| 反应窗口误杀慢反应新闻 | 默认豁免 high 强度/1-3d 持仓（参数可调）|
| 止盈目标失真（历史 MFE 随市场变化）| 用最近 N 笔滚动统计；tp1_mult 可调 |
| 分级移动止损高波动仍被扫 | 档位可调；与 ATR 初始止损叠加保护 |
| BUY 门槛提高 → 交易量下降 | 2a/2d 参数可调；先 0.4 观察，按胜率微调 |

# 九、实施顺序（建议）

1. **P1（止损体系）**：ATR 初始 → 保本 → 分级移动（forward.py + 参数表 + 后台设置）
2. **P2（出场增强）**：分级止盈（partial 字段）→ 反应窗口 → 冲高回落
3. **P3（买卖质量）**：不对称门槛 → 新鲜度分级 → 组合胜率注入
4. **P4（反思深化）**：单笔反思 → 命中验证
5. **P5（远期）**：反向新闻平仓

> 每阶段独立上线、可回退；默认参数下旧行为不变（新层在默认值时大部分是"更安全"的方向）。
