# v474 · 2026-11-19 公司侧分歧度：价值陷阱从"被折半"变成"被标出来"

## 一句话

公司票也会自相矛盾。最典型的是**"估值说便宜、盈利在砍"**——以前 `_consistency` 只会把分数折半，
但折半之后没有任何标记，复盘时分不清"这个分数低是因为生意差"还是"因为两个分量在吵架"。
v474 把这件事做成显式字段，口径与 alt 侧（v472）逐字一致，下游共用一套读取。

## 一、口径

| 盈利路径 | 参与算分歧的分量 | 权重 |
|---|---|---|
| 盈利股 | `valuation_used` / `earnings_revision_used` / `macro_tilt` | 0.50 / 0.50 / 0.10 |
| 亏损股 | `rev_yoy` / `gm_trend` / `ocf_margin` / `ocf_trend` | 0.40 / 0.20 / 0.25 / 0.15（即 `_LOSS_WEIGHTS`） |

`disp / level / confidence / bull_weight / bear_weight` 五字段与 v472 完全同一套算法：
`conf = max(0, 1 − disp/1.5)`，高 ≥0.60 / 中 ≥0.35 / 低。

**为什么宏观只给 0.10**：宏观倾斜本身已封顶 ±0.15，加进方向分最多影响 1.2%，
给它大权重会让"宏观背景"冒充"公司分歧"。但它确实是噪音源之一，所以保留 0.10 ——
既不让它主导，也不假装它不存在。

## 三、这张表里最值得注意的三件事

**1. COIN 是唯一"高分歧"，而且分数几乎为 0（+0.067）**

估值分量 +0.25（部分便宜）、盈利分量 −0.60（在砍）——这正是价值陷阱的标准形态：
看着便宜，是因为盈利预期正在往下修。**可信度只有 0.44**，影子仓位会自动被打到 1 倍以下。

**2. MSTR 出现"低分歧 + 分数≈0"（+0.007，可信 0.79）**

这不是"没信息"，而是"两条分量都指向中性"：多 0.55 / 空 0.45 是宏观 0.10 造成的轻微倾斜。
和 COIN 的"高分歧 + 0 分"完全不同 —— **同分不同质，这就是这轮要解决的问题**。

**3. 高分的票（PLTR 0.905、META 0.770、SMCI 0.725）都是"中分歧"**

多 1.00 / 空 0.10（那 0.1 还是宏观反向）—— 说明它们的强势是**两条主线都同意**，
而不是一条极强、一条极弱互相抵消。这类分数的可执行性明显高于 COIN。

## 七、现在的完整状态

**公司侧与非公司侧，现在共用同一套"分数 + 可信度"语言**：

```
原始数据 → 分量 → 分数 → 分歧度/可信度 → 方向权重打折(0.08×) → 仓位乘数打折(0.75+0.25×) → 落库审计
```

三个环节都可审计：`decision_fundamental_snapshot` 里每行都能看到分数、分歧度、可信度、乘数、完整分量 JSON。

**下一个自然的方向**：现在分歧度只影响"仓位大小"，没影响"该不该开这一仓"。高分歧 + 低分的票
（如 COIN +0.07、可信 0.44）在逻辑上应该更接近"观望"，而不是"小仓位做多"。
要不要我做**开仓阈值也按可信度收紧**（比如 `buy_min` 从 0.35 提到 0.35+0.1×(1−conf)）？
