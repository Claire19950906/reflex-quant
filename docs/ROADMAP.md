# ROADMAP

写给准备 star 或 fork 的人：这套东西现在在哪、下一步去哪、什么不做。

## 现在（v500）

- 64 项能力后端全部实现，前端只挂出 4 个页面的切片
- 决策闸四类拒单在线跑；近 156 次方向性出手，拦下 136 次（87.2%）
- 33 错因分 hard / soft / research 三层，只有 hard 进闸
- 每日 7:00 早报已跑（launchd + 六类扫描 + 三通道推送 + 去重闸门）
- **已结算样本 0 笔**——这是唯一挡住"接真钱"的东西

## 下一步（按顺序，不并行）

1. **样本到 60 笔已结算**：这是把"NULL"变成数字的唯一门槛，其余都是它的前置。
2. **能力仪表盘**：把 64 项从页面底部收成一张表，每行标"需要什么数据才出结果"。
3. **持仓导入**：CSV / 手录 → 让"命中我持仓的 3 条新闻"真的能算。
4. **每日一页**：早报从六类压成三行（持仓相关 1 条 + 今日该盯 1 个数 + 上周错 1 条）。
5. **陌生人不配 key 也能看到界面**：生成一份 demo 库，`docker compose up` 即可浏览。

## 不做

| 不做 | 理由 |
|---|---|
| 自动下单接真钱 | 样本不足 60 笔之前，等于把未验证的东西卖给你 |
| 承诺收益、晒胜率 | 同上，且会毁掉唯一值钱的东西——可信度 |
| 更多品种 / 更多数据源 | 15 品种已超过个人能消化的量，边际是"更全"不是"更有用" |
| 第 34 个错误码 | 分层讲清楚比增量重要 |

## 参与方式

- 提 Issue：用错了、数据不对、页面假空，都算。
- 提 PR：先开 Issue 说清楚改什么、为什么，再动手。
- 想接自己的数据源：`src_python/feeds/` 下加一个取数函数，缺口写进 `gaps` 就算合格。
