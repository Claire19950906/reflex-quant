# v476 · 策略版本赛马场（Variant Arena）

> 目的：同一批新闻信号、同一份 1m 行情、同一套成本口径下，并行跑多个策略版本，
> 看“改入场闸”和“改出场规则”各自到底值多少钱。只有样本、净收益、MFE 覆盖、
> 回撤、t 值都过关的版本才允许晋升。

## 为什么不是再加一个看板

系统已经有 400+ 模块、38 个前端页面、3500+ 离线测试。缺的不是新页面，
而是**同一口径下的版本对照**：

- 现在的 `quick_sim` 只有一套固定出场（TP1 0.6% / TP2 1.0% / SL 0.5% / 到期）；
- 成本闸是“软”的：样本 <6 时放行，等于没验；
- 没人知道“动态出场”比“固定出场”好多少，也没人知道“严格成本闸”会拦掉多少。

赛马场就是把这件事变成可重复的离线实验，不碰生产账本。

## 五匹马

| 变体 | 入场闸 | 出场 |
|---|---|---|
| `baseline` | 不过闸 | 固定：TP1 0.6% / TP2 1.0% / SL 0.5% / 到期 |
| `dynamic` | 不过闸 | 动态：MFE≥成本后保本、0.3% 后移动止损、20 分钟无反应撤 |
| `gate` | **软成本闸**（样本 <6 放行，与当前生产口径一致） | 固定 |
| `gate_dynamic` | 软成本闸 | 动态 |
| `gate_strict` | **硬成本闸**（样本 <6 也拒绝） | 固定 |

成本闸只看**决策之前已经结算**的 MFE：生产 `quick_sim_trades` 的已结算样本 +
本场 `baseline` 在此之前已经走完的交易。中位数必须 ≥ 1.5×往返成本才放行。
用 `exit_ts` 而不是 `entry_ts` 过滤，避免拿一笔还没走完的交易未来 MFE 决定当下开火。

## 不偷看未来的几个硬口径

1. 入场价 = 决策时间之后**第一根 1m K 线**的 `open`，不用决策当根收盘。
2. 出场只用同一份 1m K 线路径；同一根内**止损优先于止盈**（保守）。
3. 成本统一走 `cost_model.round_trip_cost_bps(asset)`，净收益 = 毛收益 − 成本。
4. 信号两层去重：
   - `news_id × asset`：同一条新闻同品种只算一次；
   - `asset + action + 5 分钟桶`：多源转载/同一事件的不同新闻，5 分钟内同向只算一次。
5. 样本 <60 笔一律不判“版本更优”，只输出观察结论。

## 晋升门槛（写死，不靠人拍脑袋）

- 样本 ≥60 笔；
- 净合计 >0；
- 净均值 >0；
- 平均 MFE ≥1.5×平均成本；
- 最大回撤 ≤10 个百分点；
- t 值 ≥1.5。

任一条不满足：`eligible=false`，只能观察。

```bash
  --db runtime/backup/pre_prune_20261119_154634.db \
  --days 1 \
  --out reports/variant_arena \
  --arena-db runtime/eval/variant_arena.db
```

产物：

- `reports/variant_arena/latest.md`：人看的报告
- `reports/variant_arena/latest.json`：完整记录（每笔 taken/skipped/no_price）
- `runtime/eval/variant_arena.db`：独立结果库，三张表 `arena_runs` / `arena_variants` / `arena_trades`

只读生产库；结果写独立库，不碰 `trident_event_bus.db` 的账本。

## 这批数据说明了什么

1. **动态出场不是主要矛盾**：`dynamic` 只比 `baseline` 好 0.2 个百分点，胜率反而从 13.2% 降到 7.9%。
   出场改得再细，也救不回入场质量。
2. **软成本闸只是少做几笔**：`gate` 从 38 笔降到 31 笔，净合计从 -11.5% 收窄到 -9.3%，
   但净均值仍然 -0.30%，没有转正。原因不是闸没用，是这批信号的 MFE 中位数本来就只有 0.14%，
   覆盖不了 25bps 成本 + 1.5 倍安全垫。
3. **硬成本闸会全拦**：`gate_strict` 31 笔“样本不足”直接拒绝、8 笔“成本不够”拒绝，
   最终 0 成交。这不是模块坏了，是当前信号集在严格口径下**没有可交易边缘**。
4. **样本远远不够**：69 条信号、31~38 笔成交，离 60 笔晋升门槛还差一半，
   所有排名只能当“相对观察”，不能当“版本更优”。

## 边界

- 这是**离线纸面模拟**，不是实盘，也不是生产 `quick_sim` 的替代。
- 没有接 FastAPI 路由、前端页面、定时任务；避免动另一个会话正在跑的线上服务。
- 生产库 `runtime/trident_event_bus.db` 在 16:47/16:59 被另一个会话重置过，
  稳定分析源用 `runtime/backup/pre_prune_20261119_154634.db`。
- 工作区有大量其他会话的在途改动，本次新增文件未 `git add/commit`。
