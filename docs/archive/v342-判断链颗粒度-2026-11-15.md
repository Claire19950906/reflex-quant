# v342 · 判断链颗粒度（结构因子进入闸门 + confidence 三量）

> 2026-11-15 · 分支 `v342-judgment-grain`
> 性质：**纯增量**。没有删除任何既有因子、端点、字段或功能；旧快照走老路径，分数不变。

## 一、这次修的是哪一段

问题不在 prompt 想得不够细，而在**细的推理没有落成可计算的数**：

| 环节 | 现状 | 后果 |
|---|---|---|
| prompt「盘面结构分析 v2」 | 要求算价位位置 / ATR 分档 / 周期共振 / 结构评分 −2~+2 | 只写在 reasoning 文本里，落库只剩 `market_confirmation` 三值枚举 |
| `market_confirmation` | LLM 输出 positive/negative/unknown，实测 **98.6% 是 unknown** | 最该起作用的「盘面确认」长期失效，退回 24h 动量代理 |
| 决策闸门 | 5 个固定权重因子（0.40/0.25/0.15/0.10/0.10） | 结构证据进不了方向分 |
| confidence | 单个 0-100 数字 | 方向 / 赔率 / 历史可靠三件事混在一个数里 |

## 二、改了什么（3 处，全部加法）

### 1. `structure_factor.py`（新增，纯函数、零依赖）
用快照确定字段重算结构评分：

```
bias = 7d趋势方向(±1)
     + 4h/1h 共振(±0.5)
     × 位置阻尼(1-0.5·贴边度)   ← 贴上沿不追多，下沿不追空
     × 波动倍数(低波动 1.2 / 高波动 0.8)
→ bias ∈ [-2, +2]
```

**取不到 ≠ 中性**：缺 price / 区间 / ATR / 趋势任一项 → `available=False`，不拿 0 占位。

### 2. `decision_guard.py`
- 新增因子 `structure`（权重 0.15），从 `market_confirmation` 让出（0.25 → 0.10）；权重和仍为 1.0。
- 结构分按 AI 方向对齐：结构偏多 + 新闻看多 = 支持(+)，结构偏空 + 新闻看多 = 反对(−)。
- 代理权重跟随主权重：`_CONFIRMATION_PROXY_WEIGHT` 0.12 → 0.05（否则可得权重和 >1，coverage 会读到 1.02）。
- 结果新增 `structure` 与 `confidence_split` 两个字段（原字段一个不动）。

### 3. `confidence_split.py`（新增）
把 confidence 拆成三量，原 `confidence` 不变：

| 量 | 含义 | 缺输入时 |
|---|---|---|
| `direction` | 可得因子权重占比（有矛盾则扣分） | None |
| `reliability` | 历史胜率 Wilson 95% 下界 | 样本 <10 → None（只报区间） |
| `odds` | `impact_curve` 预期波动 / ATR | None |

## 三、实测对比（同一条新闻 sentiment=0.6 BUY）

| 场景 | 旧分 | 旧动作 | 新分 | 新动作 | 结构 |
|---|---|---|---|---|---|
| ① 多头·中位·低波动 | +0.557 | BUY | **+0.618** | BUY | +1.80 |
| ② 多头·贴上沿（追多） | +0.557 | BUY | **+0.542** | BUY | +0.94（阻尼） |
| ③ 空头结构·新闻看多 | +0.125 | HOLD | **−0.013** | HOLD | −1.50 |
| ④ 无结构字段（老快照） | +0.471 | BUY | **+0.471** | BUY | N/A |

要点：结构支持时加分（①）；贴边追多被压（②）；逆结构时否决力明显变强（③）；旧数据完全不变（④）。
