# FAQ

**它是自动交易机器人吗？**
不是。它不替你下单，也不碰真钱（paper + MockAdapter）。它的位置在"你下单之前"和"你亏了之后"。

**为什么不接真钱？**
因为还没验证。已结算样本不足 60 笔，此时接真钱等于把未验证的东西卖给人。接真钱的前提写在 [`ROADMAP.md`](./ROADMAP.md)。

**胜率多少？**
不报。样本没到门槛就标 `NULL`。任何在这个阶段给你胜率的量化产品，都是在给你讲故事。

**和 Freqtrade / 聚宽 /  TradingView 有什么不同？**
它们回答"该买还是该卖"。这个回答"这单该不该下、下了会错在哪、上次同样的错我怎么改的"。前者是信号，后者是流程。

**为什么有 43 个错误码？记不住怎么办？**
不用记。33 类错因（E001–E033），其中"缺硬证据"一类按原因拆成了 E001a–E001j，所以注册表里是 **43 个码**。分三层：`hard` **19** 个会真的拦你，`soft` **8** 个只提示，`research` **16** 个要先统计验证才允许参与闸门。日常你只会感受到"被拦"和"被提示"。

**数据要花钱吗？**
不要。宏观走 FRED，财报走 SEC / yfinance，能源走 EIA，链上走 DefiLlama / blockchain.info，ETF 流走 farside。全是免费源，缺口会写进 `gaps`，不拿假数补。

**部署要服务器吗？**
不用。本机跑即可；要对外演示可以 Vercel + Fly + Cloudflare Tunnel 全套免费层，见 [`DEPLOY.md`](../DEPLOY.md)。

**需要 GPU 吗？**
不需要。模型走 API，本地只跑 SQLite 与 FastAPI。

**我的数据会上传吗？**
不上传。数据在本机 SQLite。唯一外发是你自己配置的大模型 API 调用。

**打开就是一片"—"，是不是坏了？**
不是。库是空的，页面在如实显示"没有可统计样本"。过上几天有数据，它就出数了。

**为什么 README 里老提"我们出过错"？**
因为出过。把事故写出来，是让人相信其余数字的方式。
