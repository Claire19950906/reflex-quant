# v470 · 2026-11-19 SOL 接入：加密三个品种全部有非公司基本面

## 一句话

SOL 从"只有期货持仓一族、判不可得"变成 **3 分量可用（−0.75，明显偏空）**：
链上资本（TVL）与链上活动（手续费）两条 DefiLlama 免费日频序列接进来，
与 COT 凑成三族独立证据。加密三个品种 —— BTC / ETH / SOL —— 现在全有可复现的基本面读数。

## 一、为什么是 TVL + 手续费，而不是"链上地址数"

| 想用的 | 能不能拿到 | 结论 |
|---|---|---|
| 活跃地址 / 交易笔数 | Solana 公共 RPC 只返回最近几十个性能采样点，没有历史日序列 | 拿不到 |
| 链上 TVL | DefiLlama 免费，**2,074 天**（2021-03-17 起） | 用 |
| 链上手续费（美元/日） | DefiLlama 免费，**2,132 天**（2021-01-17 起） | 用 |
| 期货持仓 | 库里已有 COT `sol.cot_noncomm_net`（2,889 条） | 用 |

三条互不派生：一条是资本（钱愿不愿意留在链上），一条是活动（这条链每天被用多少次、付多少费），
一条是衍生品拥挤度。这正是 v460 立的"独立数据族 ≥2"门槛需要的结构。
