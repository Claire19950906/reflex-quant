## 一、起点体检：不是覆盖率不够，是同一财季被算了两次

按 `equity_fundamentals.db_pack()` 实测 16 只美股：

| 读数 | v487 实跑 | 断档票 |
|---|---|---|
| TTM 营收 | **11 / 16** | AAPL / NVDA / MU / HUT / MARA |
| TTM 毛利率 | **11 / 16** | 同上 |
| 季数 `n_quarters` | 12~26 | 看起来"够"，实际一半是重复季 |

根因在 `_dedupe_rows`：它只按 `period_end` **完全相等**去重，而同一财季两个源的期末日并不相等：

```
AAPL  AV 月末  2026-09-30   （有利润表/现金流）
AAPL  SEC 口径 2026-09-26   （有资产/负债）
→ 旧实现当成两个季度；rows[:4] 只覆盖两个真实季度，
  TTM 的 revenue / gross_profit / operating_cash_flow 全是 None。
```

这不是"没采到"，是"采到了但没对齐"。NVDA（07-31 vs 07-26）、MU（08-31 vs 09-03）同理；
HUT / MARA 是另一回事 —— 三表里确实没有利润表，属于真缺口，不在本次修复范围。

## 二、修法：按财季聚类 + 字段级合并

`equity_fundamentals._dedupe_rows`（v488）：

```
同 fiscal_year + period 优先合并（yfinance 带 Q1/Q2/Q3/Q4）
否则期末日相差 ≤21 天视为同一财季
每季选「非空字段最多」的一条为主记录（平手 fmp > alphavantage > yfinance）
其余记录只回填空字段，不覆盖已有值、不跨季借数
```

同时修 `fundamental_factor.stmt_growth`：去年同季不再用「年份减一」做字符串精确匹配，
改为「330~400 天内最接近 365 天的一条」——2026-09-26 对 2025-09-27 这种 1 天漂移也能匹配。

**结果（同一份库、同一时点）**：

| 读数 | 修前 | 修后 |
|---|---|---|
| TTM 营收 | 11 / 16 | **14 / 16**（仅 HUT/MARA 真无利润表） |
| TTM 毛利率 | 11 / 16 | **14 / 16** |
| 利润率趋势 | 9 / 16 | **14 / 16** |
| FCF 率 | 9 / 16 | **12 / 16** |

## 三、新增：生意质量四件套（`company_depth.py`）

只从已入库三表算，零网络、零插值、只判差不奖励好：

| 读数 | 口径 | 护栏（只在下述方向打标签） |
|---|---|---|
| 毛利率趋势 | 近 4 季 TTM 毛利率 vs 前 4 季（不足 8 季退同季对同季） | 下滑 ≥2pp → `gm_down` |
| 经营利润率趋势 | 同上 | 下滑 ≥3pp → `opm_down` |
| 自由现金流率 | (TTM OCF − \|capex\|) / TTM 营收 | ≤−5% → `negative_fcf` |
| 杠杆率 | 最近一期 总负债/总资产；净资产为负单列 | ≥0.85 → `high_leverage`；净资产<0 → `negative_equity` |

另有两条口径保护：
- **capex 符号归一**：AV 给正数、yfinance 给负数，一律取绝对值再减；
- **失真不外抛**：经营利润率 >±200%、FCF 率 >±300% 判口径失真（MSTR 财库资产公允价值），
  返回 None 并写进 gaps，不再把 +2756pp 当成"经营杠杆改善"。

## 四、边界：这版**没有**把深度读数放进方向分

理由与 0.08 权重仍未被影子账本验证是同一个：
- 深度读数是同一份财报的第二次使用，未做 A/B 前加权重，等于用"看起来合理"替代"验证过"；
- 本轮只让复盘、看板、决策解释能读到它（`components.depth_*`、`flags`、`gaps`）。

**实测零改分**：同一库、同一时点，把 `_dedupe_rows` 换回旧实现逐票对比，
16 只票的方向分**逐位相同**（AAPL +0.1391 / META +0.7696 / NVDA +0.4633 / MU +0.4139 …）。
新增的 `gm_down`/`opm_down`/`negative_fcf` 只作为护栏标签出现在解释里，
`decision_guard` 文案追加一句「生意质量 毛利率X%/同比±Ypp/FCF率Z%」。

## 五、仍然看不到什么（写进每一次输出）

`company_depth._STATIC_GAPS` 会随公司侧 `gaps` 一起下发（闸门取前 4 条）：

- 无分部/地区拆分：不知道增长来自哪条业务、哪个市场；
- 无债务到期结构与利息覆盖：不知道再融资压力；
- 无管理层指引/订单/backlog：不知道增长的可见度；
- 无财报电话会与 10-K 文本：读不到管理层原话与风险披露；
- 无卖方覆盖与一致预期序列：只有下次 EPS 一个点；
- 无 DCF/EV-EBITDA：估值只有历史分位与同业倍数。

A股/港股 8 只同样下发 5 条固定缺口（无三表/无季度历史/无同业/无日历/无宏观传导），
不再让「16 只美股的深度读数」被误读成「同口径覆盖」。
