## 二、四条改动

### 1）基本面成为真正的方向因子（`fundamental_factor.py` + 权重表）

```
改前 {"news_sentiment":0.40, "market_confirmation":0.10, "structure":0.15,
      "trend":0.15, "funding":0.10, "price_fund_divergence":0.10}   基本面 = 0
改后 news_sentiment 0.40→0.32，新增 "fundamental":0.08（和仍 = 1.0）
```

- `score ∈ [-1,1]`，由两个分量合成：
  - **估值历史分位**：自身 PE 在近 365 天自累积快照中的分位（50% 分位 = 0，两端 ±1）；
  - **盈利修正方向**：TTM EPS 同比（缺则营收同比代理，标出来）× 0.65 + 最近一次 EPS 预期差 × 0.25
    + 下次一致预期相对上次实际的抬升 × 0.10。
- 只有分量都拿不到才 `available=False`，此时闸门**让出 0.08 权重**（沿用「取不到 ≠ 中性」的既有规则）。
- 锚点规则不破：没有新闻情绪锚点时，基本面不能单方面造方向（`test_fundamental_does_not_become_standalone_direction`）。
- 与新闻反向且 `|score|≥0.35` → 记 `news_vs_fundamental` 矛盾；**只记录不折减**
  （方向分已按 0.08 计过一次，再折减等于同一证据扣两次）。

### 2）财报三件套 + 财报日历 + 一致预期（抓取与读取分离）

| 组件 | 位置 | 说明 |
|---|---|---|
| 两表 | `equity_fundamentals` / `equity_earnings_events` | `db.py` 增量迁移（只加表，不动既有语义） |
| 抓取 | `equity_fundamentals.fetch_pack()` | FMP 优先；statement 端点 402/SSL 时逐端点退 Alpha Vantage |
| 落库 | `persist()` | 两表 upsert，`source` 逐行标注（fmp / alphavantage） |
| 读库 | `db_pack()` | **零网络**，还原同 shape，宏观层每轮只读这里 |
| 层 | `macro_context.fetch_fundamentals()` | 一票一行，8 条指标；读不到只有一条 `fund.unavailable` |
| 脚本 | `scripts/cron_equity_fundamentals.py` | `--tickers/--dry-run/--show`，AV 13s 节流，写锁重试 |

为什么必须分离：AV 免费档 **5 次/分钟 / 25 次/日**，FMP 免费档对 statement 端点另有额度且间歇 SSL EOF。
把它放进 22 分钟一轮的宏观层，等于把配额烧着玩，还会把判断链睡死。

### 3）`gold_etf` 与 `flow` 不再假装修好了

- `gold_etf`：SPDR 官网本机**根本到不了**（DNS 劫持 / SSL 失败，2813 轮 0 成功）。现在：
  失败结果负缓存 6 小时（不再每 22 分钟撞一次墙），note 写明「网络不可达，不是配置错，
  需要的话把 `GOLD_ETF_CSV_URL` 指向可达镜像」；解析逻辑保留（配镜像或注入 fake 仍能用）。
- `flow`：删掉 XAU/WTI 那 4 条「无免费 taker/CVD 源」的永久 `_fail` 行——它们不是「这次没抓到」，
  是**结构上就不存在**，每轮写 4 行恒定失败值会污染 ok 率统计（flow 34.9% 里小一半是它们）。
- 渲染：每层「当前不可用，不得臆造」的空行改成末尾一行「数据缺口」汇总（16 层原本会占 4~5 行）。

## 三、实测数字

```

      同比={'revenue': 83.38, 'net_income': 122.73, 'operating_cash_flow': 74.41} 毛利率=74.67

`fundamental_factor.build("NVDA")`：

```

components={'valuation_percentile': 0.884, 'earnings_revision': 0.8806, 'consensus_tilt': 0.7508}
evidence=['PE 20.48x，处于近365天 6% 分位（区间 25.4~28.8x，n=2472）',
          'TTM 营收同比 +83.4%（EPS同比缺失，代理）',
          '最近一次 EPS 预期差 +6.2%',
          '下次一致预期 EPS 2.47（较上次实际 +11.3%）',
          '下次财报 2026-11-17（1天后）']

诚实边界（同一次实测暴露出来的，都按"不猜"处理）：
- `COIN` / `RIOT` 的 PE 为负 → **不给分位**（亏损股看 PE 本身就是错指标，给"低分位"会读出"便宜=看多"的假信号）；
- `MSTR` 历史 `eq.pe` 从未取到 → 只有盈利修正分量，`valuation_percentile=None`，`detail` 里写明原因；
- `NVDA` 的 EPS 同比缺失（AV 利润表不带 EPS）→ 用营收同比代理并在 evidence 里显式标注。
