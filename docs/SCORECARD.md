## 要到 9 分，只差两件

1. **覆盖率往上抬（+0.5）**：现在实测 20%，门槛 18%。每接一个新模块抬到「实测 − 2pp」，到 60% 需要真正补测，不是改数字。
2. **拆 `api_server.py`（+0.5）**：它是唯一的巨石入口，新人第一步会卡在这。

## 要到 10 分，第三件

3. **补一页数据源清单与延迟（+0.2）**：15 个品种各接哪几个源、滞后多少，现在散在 docs 里。

## 本轮验证（不是自评，是实测）

```
$ TRIDENT_DB_PATH=backend/demo.db python3 src_python/api_server.py
$ curl -w '%{http_code}' /api/health          → 200
$ curl /api/trident2/features | jq .summary   → total 64 / P0 11 / P1 36 / P2 17
```

这条链路已固化成 CI 的 `demo-smoke` job：起服务 → 等 health 200 → 断言 64 项。红一次就说明"陌生人跑不起来"。

## 本轮顺手修的真 bug

`tests/test_repository_news.py` 在 import 期就读真实库构造参数化用例，导致 `pytestmark = skipif` 来不及生效——无库环境下 CI 是 **ERROR** 而不是 skip。已改成模块级 `pytest.skip(allow_module_level=True)`，实测 `1 skipped in 0.78s`。

## 不该为了分数做的事

加更多功能（第 9 项已经 8 分，缺的不是数量）；写更多形容词（第 8 项已满分，再加就是注水）。
