## 根因（间歇，非配置错误）

1. **bridge 单线程被慢调用堵住**：门卫一次 LLM 调用可达 ~15s；`/api/health/models` 在请求路径同步聚合模型分布 + 漏斗 + 门卫判出率 + 近 30 分钟成败，实测 7s+；叠加 SQLite 写锁，其它并发请求排队、超时。
2. **Next 反代间歇 hang up**：`frontend.err.log` 累计 **15163 次** `socket hang up / ECONNRESET / Failed to proxy`。撞上堵塞窗口时反代返 500 / 000。
3. **前端首轮取数失败后保持空态**（有意设计，不显示假值）：
   - 行情 hook（use-binance-prices）首轮未成功 → `loaded=false` → 五品种停在"加载中"；之后每 3s 轮询可自愈。
   - 信号计数 hook 走 /events/today，15s/60s 轮询，恢复后回填（当前已显示 1 空）。
   - 事件历史列表（event-bus fetchHistory）**只在挂载和时段切换时拉一次**，首轮撞卡顿失败不会自动重拉历史，只靠 SSE 增量；需手动刷新页面重拉。
   - 持仓/决策面板门控依赖 /api/health/models；该接口超时或返回 `warming_up/stale` 占位时，面板保持"空仓/未就绪"。
4. **间歇 SQL 报错**：`funnel_db_error: OperationalError: near ",": syntax error` 出现在旧的 30s 缓存快照里；本轮直接调 `funnel_stats`/`gate_health` 均正常（db_error 空），未稳定复现，列为低优先观察项。
