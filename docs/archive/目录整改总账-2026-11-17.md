## 三、踩过的坑（都是真金白银换来的）

| # | 坑 | 现在的做法 |
|---|---|---|
| 1 | `include_router()` 在 FastAPI 0.163 产生 `_IncludedRouter`，bridge 手工挂载静默丢路由 | 一律 `_include_flat()` |
| 2 | 挂载 ≠ 同进程：8000 的 `sqlite3.connect(timeout=20)` 搬进 8100 会踩满锁超时 | 跨进程优先「薄转发 + 本地兜底」 |
| 3 | 延迟回引写成 `_api.X`（`_api` 是函数）→ AttributeError，6 个 router 同时坏 | 一律 `_api().X` |
| 4 | 依赖替换正则误伤 import/def/装饰器字符串（`from x import y as _api()._T2M`、`"/api/_api().backtest/run"`） | 只替换表达式位置；写文件后必须 `ast.parse` + ruff + 冒烟 |
| 5 | 请求模型留在 api_server、端点搬走 → FastAPI 装饰阶段解析注解时报 no attribute | 模型必须跟端点一起搬 |
| 6 | 读源码文本的测试（`inspect.getsource(api_server.xxx)`、`patch.object(api_server, ...)`）搬家后必坏 | 断言/patch 目标改到新 router 模块 |
| 7 | 切片边界按「行号阈值 + 通用分隔线」→ 三次误删 | 只用语义锚点，并自检「删除行数 = 实搬行数」 |
| 8 | 同一文件多处替换复用旧行号 → 删错块 | 每次替换后重新 `ast.parse` 取新行号 |
| 9 | 对整个工作区 `git stash` 会把并行线未提交改动一起收走 | 只回退自己的文件；必要时 `git checkout HEAD -- <单个文件>` |
| 10 | 全量 pytest 被 OOM 杀掉 | 分批跑（每批 12 个测试文件） |
