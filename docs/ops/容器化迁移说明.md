# 容器化迁移说明（P2-4，2026-11-19）

## 现状

- 生产由本机 **launchd** 拉起：6 常驻 / 7 守护 / 117 cron（见 `docs/ops/进程模型清单-2026-11-19.md`）。
- 主存储是 **SQLite**（主库 + 4 个旁库），库文件在 `backend/`；运行时状态在 `runtime/`，报告在 `reports/`。
- 本地 Ollama（11434）跑在宿主机；后端通过 `OLLAMA_URL` 访问。

## 已落地的容器骨架

| 文件 | 作用 |
|---|---|
| `backend/Dockerfile` | 后端镜像：Python 3.14-slim，按 `requirements-lock.txt` 锁版本安装，非 root，内置 `/api/health` 健康检查 |
| `frontend/Dockerfile` | 前端镜像：Node 20 多阶段构建，`next start` 跑 3030 |
| `docker-compose.yml` | 三服务编排：`backend-bridge`(8100) / `backend-master`(9001) / `frontend`(3030)，库与 runtime/reports 挂卷 |

> 骨架**尚未在生产启用**；当前仍以 launchd 运行。容器化是目标态，需按下面清单逐项迁移并回归。

## 迁移前必须先归类的进程

进程模型清单里的 130 个作业，不能整体塞进一个容器，要分三类：

| 类别 | 数量 | 容器化去向 |
|---|---|---|
| 常驻 HTTP 服务（bridge / master / frontend / engine / crowd-pulse / ollama） | 6 | 进 compose 服务，配健康检查与重启策略 |
| 守护 watchdog（engine / lock / memory / pause / stops / service-guard） | 7 | 先进 sidecar 或独立 cron 服务；确认它们依赖的本机状态路径可挂卷 |
| 一次性 cron（数据回填 / 复盘 / 归档 / 统计） | 117 | 迁到容器内 cron、或宿主调度器调用容器 `run --rm`；逐条核对时间口径与幂等水位 |

### 未解决项（迁移时再定）

1. **SQLite 并发**：容器化后多进程仍抢同一 WAL 写锁；跨容器访问同一库文件需挂共享卷，注意 `database is locked`。归档/回填类任务优先用只读副本或错峰。
2. **本地 Ollama**：当前在宿主机。容器内用 `host.docker.internal:11434` 访问；要完全容器化需另起 ollama 服务并挂模型卷。
3. **117 个 cron 的幂等水位**：迁移调度器后，确认各任务读取的水位表/时间戳仍正确，避免重复结算（参考偏好：中断后以恢复时刻为新起点，不补停机堆积）。
4. **密钥 / .env**：`backend/.env` 已 gitignore；容器化后改用 env 文件或密钥管理，不要打进镜像层。
5. **日志采集**：现状写 `logs/`、`runtime/*.log`；容器化后走 stdout（`PYTHONUNBUFFERED=1`）或挂卷，再统一采集。

## 卷与持久化约定

| 宿主路径 | 容器内 | 内容 | 是否必须持久化 |
|---|---|---|---|
| `backend/*.db`、`*.db-wal/shm` | `/app/data` | SQLite 主库与旁库 | 是 |
| `backend/runtime/` | `/app/runtime` | 水位、丢写账本、守护状态 | 是 |
| `backend/reports/` | `/app/reports` | 影子账本、健康报告 | 建议 |
| `backend/.env` | 注入 env | 密钥与口径参数 | 是（不进镜像） |

## 上线 / 回滚步骤（目标态）

1. 先在隔离环境 `docker compose build` 三镜像，`docker compose config` 校验编排；
2. 只起 `backend-bridge`，挂**副本库**跑只读冒烟 + `pytest -m smoke`；
3. 逐服务切流：frontend → bridge → master；cron 先迁只读类，再迁写库类；
4. 每个服务保留 launchd 旧进程作为回滚退路，确认容器态稳定后再停用旧作业；
5. 回滚：`docker compose stop` 对应服务，重新 `launchctl start` 旧作业；库文件未做破坏性迁移前可直接切回。

## 禁止事项

- 不要把 `.env`、`.db`、密钥文件 `COPY` 进镜像；
- 不要在未归类 cron 前整体 `docker compose up` 让回填任务重复跑；
- 不要让容器以 root 运行（镜像已 `USER appuser`）；
- 对外暴露端口前先过 CORS / 白名单 / token 鉴权复核。
