## 一句话结论

**软件落地：已经成立；产品落地：半个；商业落地：不成立。**
真正拦住它的不是"策略不够好"，而是**新闻在 1 小时内没被认领就被静默归档——今天 66.5% 的新闻根本没进分析**。
所以"89% 降级 / 99% HOLD"不是策略的性格，是**漏斗吞吐事故的余波**。

## 三、根因链：从新闻到仓位，五个断点

**R1（最上游、今天最大的）新闻只有 1 小时的分析窗口。**
运行中的 engine 进程环境是 `NEWS_ANALYZE_MAX_AGE_HOURS=1`（`.env` 和 `config.py:1402` 都是 6）。
超过 1 小时没被认领的 PENDING，会被 `engine/ai_worker.py:768` 的 `_BATCH_EXPIRE_SQL` 归档成
`status='FILTERED'`，但**不改 `is_noise`**；而认领 SQL（`ai_worker.py:679/709`）只取
`status='PENDING' AND is_noise=0` → 这批新闻**结构性不可能再被分析**，也不会进"待分析"计数。
今天 742 条就这么没了，含 52 条门卫已判"可交易"的。

> 一行可验证的 A/B：把 engine 的 `NEWS_ANALYZE_MAX_AGE_HOURS` 从 1 改回 6，看 DONE 占比是否从 4.8% 抬起来。
> 这是**今天唯一一个改配置就能拿到量**的动作，优先于任何代码改动。

**R2 预路由没"没生效"，是"抓错了类别"。**
261/265 条 target_none 发生在 17:55 之前（`realtime_filter.py:1888` 的 L0-POOL 上线前），是存量；
17:55 之后 3 条都不是个股稿。问题在召回：`feeds/news_router.pool_out_reason` 实测只拦下 **10.6%**，
**87.5%（232 条）是"别国宏观/海外杂讯"**——以色列 CPI、埃及最低工资、马来西亚棕榈油出口、法国示威、
美国政客口水，来源 `sina_flash` 一家 184 条。路由根本没有"非池内市场"这一类。

**R3 缺的是"资产归属"，不是更长的词表。**
`feeds/news_router.py:28` 的 `POOL_KEYWORDS` 把"CPI / 美联储 / 黄金 / 原油 / ETF"当放行条件——
这些既是池内驱动词，也是别国本地数据的常用词，所以宽词把杂讯救回来了（5 条个股 + 大量海外数据）。
门卫的规则兜底 `realtime_filter.py:1693-1730` 只是小口子（实测只放行 18/265），主渠道是 L1/L2 的正向放行。

**R4 LLM 供给是硬约束。** 17:11 起门卫/主分析全池熔断（quota/auth/net/ratelimit 全 closed，累计 101 次），
`[GATE] gate LLM 不可用 → 规则兜底放行` 刷屏，`llm_empty` 71 条即同源。
20:44 后决策停写，engine 22:01 重启、22:03 认领 8 条卡在 PROCESSING；
而 `/api/health/models` 返回 `channels=[] / warming_up=true / analyzed_24h=0`（与实际 53 条不符）→ **监控本身失真**。

**R5 边际与验证周期。** 20min 持有 + 30bps 成本，成本吃掉单笔亏损的 1/4。
要证明"55% 胜率、95% 区间下界过 50%"，约需 **380 笔结算**；当前 1–2 笔/日 → 一年以上。
结论：**不能用"实盘业绩"做说服路径**，产品定位必须绕开 alpha。

| 形态 | 卖什么 | 前提 | 可行性 |
|---|---|---|---|
| **A 单机自用版** | 全功能、本地、免费数据源 | 无 | 已成立 |

| **C 事件雷达** | 新闻→品种映射 + 影响量级，**不做方向** | 实质分析覆盖率 ≥90% | 门槛最低，S12 已 76.9% |

## 五、90 天路径（按顺序，别跳）

1. **恢复吞吐**：engine env 改回 6h；把"FILTERED 但 is_noise=0"的归档语义拆开（新增 `ARCHIVED` 状态或至少写 `is_noise` 之外的一列），别再让"放行"和"丢弃"共用同一个值。
2. **把漏斗做成可观测**：每天跑一次 `probe_target_none_root_cause.py`，只盯三个数——DONE 占比、归档里"可交易"条数、方向性决策条数。
3. **路由加"市场归属"维度**：先做源级（`sina_flash` 全品类流，先按"中国/美国/其他"打标），再做品种级（是否可能推动 BTC/XAU/WTI/ETH/SOL）。
4. **样本流水线**：稳定 ≥3 笔方向/日、全部结算；60 笔只看区间；同时建"反思结论↔实际结果"对照表（S5 确认率 10% 太低）。
5. **成本账本 + 1 份外部审计样本**：`t2_cost_ledger` 现在是空表，deck 里 "$50/千条决策" 无法复核。

**可以说"落地了"的判据**：DONE 占比 ≥50%、归档里"可交易"条数为 0、降级率 <30%、连续 30 天方向性 ≥3/日、成本账本可复核、有 1 份外部审计报告。

## 六、对外材料必须改的三处

1. **删掉**"the hardest technical part is done"——今天的事实是：最硬的在漏斗吞吐，不在反思维度。
2. **合规从 Low 调成 Medium**，并明确"只做审计/分析、不下单、不代客"。
3. **单位经济**：$50/千条决策属估算，未核算前不要写进融资材料；有账本后再写。
