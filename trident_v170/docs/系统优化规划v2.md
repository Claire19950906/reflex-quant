## 4️⃣ 知识库（历史数据/K线/经验/金十数据 + 节省 token 检索）✅ 基础已做

**现状**：review_insights（经验回灌）+ 复盘报告 + trade_reflections + market_ticks（K线）+ ai_decisions（判断记录）。

**建议（重点是节省 token 的检索）：**

| 层 | 方案 | 优先级 |
|---|---|---|
| **存储** | 现有 SQLite 已存大部分（K线/经验/判断）；金十数据接入后入库 | P0 |
| **检索方式 A（低成本）** | 关键词 + 时间窗过滤：分析新新闻时，按「品种×事件类型×近期」检索相关历史判断/经验，取 top-k 注入 | P0 |
| **检索方式 B（向量化，省 token）** | 用 embedding 模型（如 bge-m3 中文）把历史经验/判断向量化 → 语义检索 top-k（只注入最相关的 3-5 条，每条截断 ≤100 字）→ **token 消耗大幅下降** | P1 |
| **金十数据库** | 金十数据中心数据接入（日历/情绪/讲话）| P1 |

**关键**：检索只注入**最相关**的 top-k，而不是全量经验——这是省 token 的核心（现注入 8 条经验 + 信号全量，可优化为按相关性动态取）。

## 7️⃣ 量化新闻判断能力（分维度：冲突类 / 趋势类）🟡 P1

**核心：把新闻量化为可计算的多空力量。**

| 维度 | 定义 | 量化方式 | 应用 |
|---|---|---|---|
| **冲突类**（突发/高影响）| 地缘冲突、突发事件、黑天鹅 | 事件强度评分（event_strength）+ 突发标记 → **直接 BUY/SELL 信号**（高置信快速入场）| 入场决策 |
| **趋势类**（力量趋势）| 趋势性新闻累积的方向力量 | **上涨力量 / 下跌力量**：按品种统计近期利好/利空新闻的累积分数（sentiment × 权重）+ 动量（K线涨跌）→ 净力量值 | 买卖节点、止损位、大中趋势判断 |
| **量化输出** | 每条新闻输出结构化力量分 | prompt 增加字段（如 `bull_power` / `bear_power` 或净力量值）| 注入决策 |

**落地**：
- 🟡 新闻力量聚合器：按品种 × 时间窗聚合多空力量（类似现有 sentiment 平均，但加权重/衰减）
- 🟡 趋势辅助：力量值 + K线趋势（MA/动量）→ 建议入场节点与止损位
- ⬜ 长趋势判断：周/月级力量累积 → 大趋势方向
