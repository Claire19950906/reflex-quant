# 市场风格（叙事逻辑）变化感知与自适应方案（草案 v1）

> 状态：设计对齐稿。目标：让系统像人一样感知「市场现在在讲什么故事」，并在故事换挡（regime switch）时**提前预警、自动下调旧叙事置信度、触发资产图谱重新推理**，而不是等连续亏损之后才事后归因。

## 0. 一句话目标

把「资产图谱」从**静态的因子清单**升级为**可变的市场叙事状态机**：每个资产当前处于哪个「叙事逻辑（regime）」，由实时数据判定；当叙事切换时，系统在亏损扩大前就嗅到预兆。

## 1. 问题诊断：为什么黄金叙事会「大错特错」

### 1.1 八段式把黄金叙事写死成了静态定性

`engine/ai_worker.py` `_SYSTEM_PROMPT` 第二层八段式的第一段：

```
[资产性质] 各品种定性：XAU=避险/抗通胀/央行储备；...
```

问题：
- **「抗通胀」多数时期是错的**——黄金不是机械地抗 CPI，它抗的是「预期外通胀 / 实际负利率 / 货币信用贬值」。
- **漏掉了黄金的第一定价变量「实际利率」**（10Y TIPS 实际收益率），它才是金价的主驱动。
- 静态定性意味着：无论现在是「央行购金去美元化」行情、还是「降息交易」行情、还是「地缘避险」行情，AI 都拿同一套「避险/抗通胀/央行储备」去套，套不上就硬掰 → 方向判断系统性偏移。

### 1.2 资产图谱是「长时记忆」，没有「短期风格状态」

`asset_graph.py` 是累积因果节点（长时记忆），靠「命中上调置信度、消失衰减失效」更新。两个天然缺陷：
1. **滞后**：regime 切换时，旧节点要在几轮「未再出现」后才衰减，期间一直误导判断；
2. **不区分层级**：把「黄金当前主线叙事」和「黄金的慢变量（如美元储备货币地位）」混在同一个节点池里，没有「当前 regime」的概念。

### 1.3 失败被归因了，但没有变成「切挡」动作

`history_review` 的 23 类失败框架里，已有三个 code 直接指向「叙事/风格错」：
- **code 7** 信号质量差/影响度误判
- **code 11** 市场状态误判（震荡市用趋势逻辑，或反之）
- **code 13** 联动传导忽略（忽略美债/美元/原油/加密的定价锚突变）
- **code 23** 经验误用/过拟合（历史规则套用到不适用的市场状态）

但这些归因目前只沉淀成文本规则，没有触发「切换 regime」这个**状态动作**。所以系统能「知道上一笔为什么错」，却不能「提前知道上一笔的错是因为换挡了、下一笔要按新挡跑」。

## 2. 核心概念：把「叙事逻辑」抽成可变状态（Regime）

**Regime = 某资产当前主导叙事 + 主导因子 + 资金面特征 + 价格行为特征 + 日历锚**。

每个资产定义**有限个离散 regime**（不是连续向量，方便判定与切换）。以黄金为例：

| regime | 主导叙事 | 主导因子 | 资金面特征（坐实信号） | 价格行为 | 失效信号（换挡预兆） |
|---|---|---|---|---|---|
| 实际利率逻辑 | 金价≈实际利率的反面 | 10Y TIPS、DXY、Fed 政策预期 | 金价涨而 ETF 流出=利率升 | 与 TIPS 强反向 | 金价与 TIPS 同向背离 |
| 央行购金/去美元化 | 储备多元化、美元信用松动 | 央行购金量、美元信用 | 央行持续购金、ETF 平淡 | 稳涨、少脉冲 | 央行购金节奏放缓 |
| 地缘避险 | 尾部风险对冲 | VIX、冲突升级 | ETF 脉冲流入、COT 投机增 | 事件驱动脉冲、快涨快回 | 冲突缓和/停火 |
| 降息交易/宽松 | 宽松预期推实际利率下行 | Fed 点阵图、EFFR | ETF 流入 + 实际利率下行同向 | 趋势慢牛 | 通胀回升打断降息 |
| 滞胀/通胀交易 | 再通胀、货币贬值对冲 | CPI、TIPS BE 盈亏平衡通胀 | 商品普涨 + 黄金同涨 | 跟随商品 beta | 通胀见顶回落 |

> 说明：上表是**产品口径草案**，regime 的个数与命名、每个 regime 的主导因子，需要你拍板（见 §9 决策点）。

## 3. 总体架构：三层

```
[Regime 定义层]  regime_defs（每资产 N 个 regime 的静态定义表，配置可调）
       │
       ▼
[Regime 感知层 NEW]  market_regime.py（纯函数/纯规则，确定性）
       5 个信号源 → 输出「每资产：当前 regime + 置信度 + 切换风险分」
       ① 价格-资金背离  ② 新闻主题漂移  ③ 日历/交割锚
       ④ 连续亏损+归因聚类  ⑤ 资金面转向
       │
       ▼
[Regime 切换预警层]  动作分层 L0 观察 → L1 提示 → L2 压制 → L3 换挡
       │
       ▼
   回灌 ai_worker prompt + 触发 asset_graph 重新推理
```

**核心原则**：
1. regime 判定**只算结构化事实**，不让 LLM 自己猜「现在是什么风格」（会背书、会漂移）；
2. 切换预警**分层处置**，弱信号只提示、强信号才压制交易，不把风控动作夹带进 prompt；
3. 任何一层失败不影响主流程（fire-and-forget）。

## 4. Regime 感知层：5 个信号源

### 4.1 价格-资金背离监测（价格行为 vs 当前 regime 预测）

复用 `technical_indicators.py`（RSI/量价/背离）+ `macro_context`（CFTC 净头寸、黄金 ETF、funding）。判据：**当前 regime 预测的价格走势与实际走势持续背离** = 叙事可能失效。例：处于「实际利率逻辑」时，TIPS 下行但金价不涨反跌 → regime 失配信号。

### 4.2 新闻主题漂移检测（"金十都在推什么新闻"）

对金十快讯/财经日历做**滚动关键词聚类**（纯函数，不需新数据源）：
- 维护「叙事词典」（避险/加息/降息/购金/通胀/地缘/流动性…），每 24h/7d 滚动统计各主题**频次分布**；
- 用突变检验（主题占比环比跳变超阈值）识别「市场叙事正在漂移」；
- 输出 `narrative_shift = {from, to, score 0-1}`。
- 数据源：`jin10_mcp.fetch_jin10_flash()` + `fetch_jin10_calendar()`，**已具备**。

### 4.3 日历/交割锚（"okx 交易日历"）

- **金十财经日历**：`jin10_mcp.calendar_events()` / `upcoming_events()` 已有高星事件（FOMC/CPI/NFP）计划时刻 → 作为 regime 的「事件开关」（议息会前=降息交易窗口、CPI 前=通胀交易窗口）。
- **OKX 交割/交易日历**：**当前缺口**——现只接了 XAU-USDT-SWAP 的行情/费率/OI（`quote_sources.fetch_okx_*`），**没有交割日/到期日**。需新增接入 OKX 交割日历（或季度交割/期权到期），作为「衍生品结构 regime」的日历锚（交割日前后资金费率/基差异常 = 换挡预兆）。

### 4.4 连续亏损 + 归因聚类（"连续几次亏损"）

复用 `history_review` 23 类框架，做**滚动归因聚类**：
- 对近 N 笔同资产已结算交易，统计归因 code 分布；
- 若 code ∈ {7, 11, 13, 23}（叙事/风格类）占比连续超阈值，判「该资产当前 regime 已失效」——这是「连续亏损」的结构化版本。

### 4.5 资金面转向（坐实 vs 背离的斜率）

复用 `macro_context`：黄金 ETF(SPDR) 环比、CFTC 非商业净头寸、恐慌贪婪 FNG、加密 funding/OI。对每类资金面做**滚动斜率**，识别「由流入转流出」的转向点，作为 regime 换挡的领先信号。

## 5. Regime 切换预警与动作（分层处置）

| 层级 | 触发条件 | 动作 |
|---|---|---|
| **L0 观察** | 单一信号源（如仅主题漂移） | 只记日志，不影响交易 |
| **L1 提示** | 双信号共振 或 出现「连续亏损」预兆 | 告警（走既有 alert 通道）+ 该资产决策置信度下调一档 |
| **L2 压制** | 三信号 + 归因命中 code 11/23 | 该资产 `decision_guard` 收紧（评分门槛上浮）、暂停相关经验回灌（防 code 23 过拟合继续套错） |
| **L3 换挡** | 确认切换（背离+资金转向+叙事漂移齐备） | 触发 `asset_graph` 重启推理：旧 regime 节点标 CONTRADICTED + 写入新 regime 节点 |

## 6. 与八段式 / 资产图谱的关系（含「删前两段」落地）

### 6.1 删掉八段式前两段 `[资产性质]` `[因素排行]`

- **理由**：这两段正是「静态定性」的载体（`XAU=避险/抗通胀/央行储备` 就是写死在这里），是黄金叙事错的直接来源；应由「当前 regime 快照」注入替代。
- **落地影响**（需同步处理，避免留死字段）：
  1. `reasoning_path` 从「八段+总结」改为「六段+总结」：`[驱动力]→[水位博弈]→[叙事逻辑]→[跨资产资金]→[反共识结论]→[逻辑自检]→[总结]`；
  2. 原 `asset_nature` / `factor_ranking` 两个 JSON 字段，改为由 `market_regime` 计算的**结构化 regime 快照**直接注入（不再让 AI 自由发挥，防背书/漂移）；
  3. `门卫四步核对`、`score 锚定`、`多品种规则`、`铁律 3`（分析对象=新闻主体）里引用 `[资产性质]/[因素排行]` 的表述同步去引用；
  4. `[叙事逻辑]` 段保留，但输入从「AI 自己想的静态定调」改为「用户：当前 regime=实际利率逻辑｜主导因子=10Y TIPS｜切换风险=中」。

### 6.2 资产图谱回归「市场叙事逻辑」

- `asset_graph` 增加一类 **regime 节点**（与普通因子节点区分，存「当前主线叙事 + 置信度 + 版本」）；
- regime 换挡时，用已有核验状态机（CONFIRMED/UNCONFIRMED/CONTRADICTED）快速标记旧叙事被事实反驳，而不是等几轮衰减；
- 归因注入时，`history_review` 的 code 11/13/23 命中优先映射到「regime 失效」，而非散落成文本规则。

## 7. 数据源现状与缺口

| 信号源 | 现状 | 缺口 |
|---|---|---|

## 8. 实施计划（分阶段）

- **Phase 0（先修认知，零新数据源）**：① 修黄金 `[资产性质]` 静态定性为「实际利率主导」的正确框架；② 删八段式前两段并同步字段/段落引用；③ regime 定义表草案。
- **Phase 1（纯函数，可单测）**：新建 `market_regime.py`，实现 4.2 新闻主题漂移 + 4.4 连续亏损聚类 + 4.1 价格-资金背离（复用 technical_indicators / history_review，纯函数无 I/O）+ 单测。
- **Phase 2（接入）**：regime 快照注入 `ai_worker` prompt（替换前两段）+ L0-L2 切换预警接 `decision_guard` / 告警。
- **Phase 3（数据源）**：接 OKX 交割/交易日历。
- **Phase 4（闭环）**：L3 换挡 → `asset_graph` 重启推理 + 旧节点衰减/标 CONTRADICTED。
