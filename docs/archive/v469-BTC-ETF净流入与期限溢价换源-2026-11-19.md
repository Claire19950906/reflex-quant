# v469 · 2026-11-19 BTC 现货 ETF 净流入接上；美债期限溢价确认换源

## 一句话

加密终于有了"真金白银的增量资金"这一层：**733 个交易日**的美国现货 ETF 每日净流入进库，
BTC 变 7 分量。同时把美债期限溢价的最后复核做完——纽约联储这条免费路彻底走不通，
结论从"再试试"改成"必须换源"。

## 一、BTC ETF 净流入：为什么这条比链上更重要

| | 链上活跃度（v468） | ETF 净流入（本轮） |
|---|---|---|
| 回答什么 | 网络有没有人在用 | 有没有新钱进来 |
| 数据性质 | 使用量，与价格不直接挂钩 | 申购/赎回，真金白银 |
| 方向能不能讲清 | 只能说"扩张通常偏多"，属假设 | 申购=买现货=直接买压，方向清楚 |
| 是否可被操纵 | 刷地址/刷笔数成本很低 | 篡改要动托管账，成本极高 |

所以链上给 0.22 权重、ETF 给 0.14，加起来 0.36 —— **加密的"使用度 + 资金流"两层终于都有了**。

## 三、分量与实测

`etf_flow 0.14`：20 个交易日累计净流入的历史分位 → `(p−0.5)×2`，流入=偏多。

BTC 从 6 分量变 **7 分量**，分数 +0.1601 → **+0.0564**：

| 分量 | 权重 | 读数 | 分 |
|---|---|---|---|
| `hashrate` 算力 30 日 | 0.18 | +14.8% | +1.00 |
| `onchain_tx` 交易笔数 30 日 | 0.10 | +20.2% | +1.00 |
| `onchain_addr` 活跃地址 30 日 | 0.12 | +7.1% | +0.71 |
| `funding` 资金费率 | 0.30 | 51% 分位 | −0.03 |
| `stable_supply` 稳定币供应 | 0.26 | −3.1% | −0.52 |
| `oi_level` 未平仓 | 0.16 | 59% 分位 | −0.18 |
| **`etf_flow` 20 日净流入** | **0.14** | **−3,713 百万美元（6% 分位）** | **−0.88** |

**这张表就是最该看的东西**：链上三个分量全绿（有人在用、算力在涨、结算在扩），
但**20 天里 ETF 净赎回 37 亿美元，处在历史 6% 分位**——使用度和资金流方向完全相反。
BTC 被压回 +0.06，接近中性。这种时候"链上很强"的故事站不住，因为卖压来自托管端而不是链上。

## 四、美债期限溢价：确认必须换源

| 入口 | 结果 |
|---|---|
| `acmtp.csv` | 返回 HTML 首页（不是 CSV） |
| `acm_tp.csv` | 返回 HTML 首页 |
| `ACMTP10.csv` | 连接失败（3 次重试） |
| `ACMSeries.zip` | SSL `UNEXPECTED_EOF` |
| FRED `fredgraph.csv?id=ACMTP10` | HTTP 404 |
| 官方 JSON API `api.stlouisfed.org` | 序列不存在（ACM 序列不在 FRED 公开列表） |

**结论**：这台机器到 `newyorkfed.org` 与 `stlouisfed.org` 的 TLS 通道都不稳，
且 ACM 序列本身不在 FRED 公开接口。**期限溢价必须换源**（Wind / Bloomberg / 本地 Wind 插件），
不再原样重试。
