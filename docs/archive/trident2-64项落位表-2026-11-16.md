## 二、怎么组织的

```
backend/src_python/trident2/
├── catalog.py      # 64 项 FeatureSpec：id / 批次 / 类别 / 说明 / 依赖 / 优先级 / 落地位置
├── types.py        # FeatureResult：status 仅 ok|no_data|not_configured|error
│                   #   硬校验：ok 必须有非空 value；非 ok 不许带 value；NaN/inf 一律过滤
├── context.py      # Context：所有读数集中入口（K线/盘口/新闻/宏观/外部指标/纸面账本）
├── store.py        # 15 张 t2_* 表 + 记录/告警/纸面账本写入
├── registry.py     # @feature(id) 注册 + 模块加载容错（缺模块只 warn，不 500）
├── pipeline.py     # run_one / run_many / run_all(P0→P1→P2) / status_snapshot
└── features/
    ├── health.py    # 8 项   系统健康与巡检
    ├── risk.py      # 9 项   风控与执行（纸面/dry-run）
    ├── monitor.py   # 8 项   市场监控（上）
    ├── monitor2.py  # 13 项  市场监控（下）
    ├── research.py  # 10 项  研究复盘
    ├── behavior.py  # 6 项   人与行为 / 交互
    ├── money.py     # 6 项   资金管理
    └── trust.py     # 4 项   结论可信
```

四条硬约束（写在 `trident2/__init__.py`，并在 `types.py` 里强制）：

1. **数据必须真**：每个结果带 `evidence.as_of` + 来源表；查不到就 `no_data`，不用 0 或空字符串顶替；
2. **结论必须有样本量**：`sample_size` 写清楚，样本不足时在 `notes` 里直说「不构成结论」；
3. **交易动作只到纸面**：所有下单/平仓/改单都写 `t2_*` 纸面账本或只出草稿，不碰真实交易所；
4. **告警必须可回溯**：先落 `t2_results`，再按 F35 的分级 + 冷却去重发 `t2_alerts`。

### 4.3 回放样本的结论（是发现，不是 bug）

2,030 笔扩量后的读数（每一笔都可用 `entry_ts` 追回真实 1m K 线复核）：

| 指标 | 数值 | 怎么读 |
| --- | --- | --- |
| 净收益均值（扣 30bps） | **−0.3009%** | 每笔平均亏 0.30 个点 |
| 毛收益均值（不扣成本） | **−0.0009%** | 方向本身几乎零收益 |
| 毛胜率 | **48.08%** | ≈ 掷硬币，没有预测力 |
| 净胜率 | **7.39%** | 30bps 成本把 48% 的毛胜率打成 7% |
| 每笔成本 | 0.30% | 与 `quick_sim_trades` 的 30bps 同口径 |

**结论不是"方向算错"，而是"没有 edge + 成本吃掉一切"**：毛收益 −0.001%、毛胜率 48% 说明新闻方向标签本身不带预测力；即便把成本压到 0，这套策略也只是打平。两条可执行推论都写进了 value 的 `caveat`：①要止损在成本上，只能靠**减少交易频次 / 提高入池门槛（impact 高分档）或降低单笔成本（限价单、maker 费率）**；②不要把新闻评分当置信度——F59 的 ECE 0.785、5/5 分桶高估，说明评分高的事件并不更准。

这也是为什么 F12 / F45 / F59 都同时报 `avg_gross_pnl_pct` 与 `avg_pnl_pct`：只看净收益会把问题归因到"模型乱开单"，看毛净对照才能定位到"成本结构"。

### 4.4 顺手修掉的真 bug

1. **F07 VaR 单位错**：日收益是百分比单位（BTC 日 σ≈2.2%），原代码直接乘 `sigma * equity`，把 3.6% 算成 **361% 权益**。已改为 `sigma/100 * equity`。
2. **F01 / F60 被 `NONE` 挡住**：近期新闻 72h 内 2,403 条 `asset=NONE`，按时间取前 200 条全是不可回放标签，导致「事件研究」全空。已改为只取 `kline_bars` 里真实存在的标的。
3. **F50 取不到资产**：`t2_interventions` 表没有 `asset` 列，代码却读 `r["asset"]`，有记录也会判「缺资产」。已改为从 `target` 解析标的代码。
