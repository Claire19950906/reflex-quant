按证据强度分层：哪些能信，哪些不能 这是整份评估最该被记住的一节

可以信EVIDENCE

  • 事件雷达与去噪：双源采集 + L1 关键词 + L2 LLM，273 条 NONE 判定正确，93% 的 NONE 是真无关（v414 审计）。
  • 行情归因：事后解释与因果对齐，S6 事前因果占比 100%，n=250。
  • 错误编码与复盘：E001–E033 七层反思，能把坏交易归到具体层；反思维度 566 条。
  • 异动归因覆盖：S7 被归因覆盖率 52.1%，n=493。
  • 盘面确认：唯一有正增量的因子，方向可复现，但样本还太小。

不能信NARRATIVE

  • 方向预测：影子账本 40.2%、独立信号 40.0%，均低于随机。
  • 幅度预测：权重判别力 ρ≈0.2，只解释约 4% 方差。
  • 择时：固定 2h / 4h 窗口；fast_rise 里 68% 其实是匀速 drift，没有时点 edge。
  • 自评置信度：门槛 0 → 39.8%，门槛 20 → 37.5%，门槛 30 → 16.7%。筛掉的是样本量，不是坏信号。
  • 「99% HOLD = 保守」：442/494 是降级兜底，不是判断。

下一步：先让判断真的发生，再谈准不准 顺序不能反。没有有效样本，校准曲线画不出来；没有校准，阈值仍然是拍脑袋

  1. 01

    先修产能，而不是修模型

    P0-A1 已落（v434）：pool-blocked 带轮次 / 已等待 / 最近可恢复倒计时，看门狗 6 小时宽线；P0-A2 主动探测先不上（冷却到期会自动放行）。P0-B 本地 3B 已经在 gate 池（LOCAL_LLM_FAST 的 purpose 含 gate），主分析保持 LOCAL_LLM_MAIN_ENABLED=0——3B 出方向会污染决策表。P0-C 认领优先级与 filter_reason 已由 v408 / v419 / v432 落地。

    还有一个此前没被点名的产能杀手：引擎正被外部会话每几分钟 kickstart -k 一次（今日近 1 小时 SIGTERM×9，ops-audit 已报警）。落库是批末一次性提交，每杀一次就作废一批——零产出小时不能只记在熔断头上。另修了看门狗的回收判据：processing_at 为空的 PROCESSING 行原来永远判不了死（今日 6 条从 18:00 挂到重启），现在按新闻入库时间兜底，已实测自动回收 8 条。验收：零产出小时 ≤1（今日 5/9）、强杀 0 次、僵尸靠看门狗自动回收、不靠重启。

  2. 02

    别动阈值，先攒样本

    连跑 2–4 周，目标有效结算 ≥ 60 笔。门槛每收紧一档都在删证据，当前 n=15 时任何命中率都不该被当成结论。

  3. 03

    把「盘面确认」做成按品种的硬闸

    按品种分别启用，不要全局硬上；确认动作本身要留痕（pre_confirm + 决策前 30 分钟的真实涨跌）。目标：先追平随机。

  4. 04

    品种分层，允许停单

    BTC 单独跑；XAU / WTI 先停方向单，只保留事件雷达与归因。砍掉两个负期望品种，比调参更快见效。

  5. 05

    用校准替代自评信心

    把 confidence 从「感觉」换成可验证概率：Brier score + 校准曲线，按品种、按事件类型分别校准。目标 Brier ≤ 0.25 且单调。
