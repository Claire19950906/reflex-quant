## 二、具体改动

### 1. 成本
- `backend/src_python/cost_model.py`
  - `_ASSET_CLASS_BPS`：`WTI/BRENT/OIL` = fee 10 + slip 5，round-trip 30bps。
  - `_ASSET_ALIASES`：`WTIUSD/USOIL/CL → WTI`，`BRENTUSD/UKOIL → BRENT`。
- `backend/scripts/backfill_quick_sim_cost_v483.py`（新增，幂等）
  - 只处理 `settled=1 AND cost_bps=0 AND (gross_pnl_pct IS NULL OR mfe_pct IS NULL)`。
  - `gross = 当前 pnl_pct`（当时成本为 0，当前 pnl 就是毛值）；`net = gross - cost/100`。
  - MFE/MAE 为空时按 BUY/SELL 方向从 entry/max/min 补算，负值夹到 0。
  - 重算 `pnl_usdt`、`verdict`。处理过后 `cost_bps>0`，二次运行 0 行。
- 验证副本：`backend/runtime/eval/pre_prune_costfix.db`（快照副本，不是 live）。

### 2. 门卫
- `backend/src_python/quick_sim.py`
  - `pending_signals` 质量 SQL 和 legacy SQL 都加 `AND COALESCE(rn.gate_unavailable,0)=0`。
  - 老库/测试库没有 `gate_unavailable` 列时自动退回“不过滤”，避免 SQL 直接报错。
- `backend/src_python/db.py`
  - `log_ai_call`：`status != "ok"` 且 `error_code` 为空 → 写 `"unknown"`。
  - 历史 1,544 条空码**没有回填**：现有字段无法可靠反推超时/限流/鉴权/网络，填具体码就是伪造。

### 3. 标的路由
- `backend/src_python/target_resolver.py`
  - 新增 `resolve_specific_one(text)`：
    - 排除 `CN_STOCK/HK_STOCK/US_STOCK/INDIVIDUAL_STOCK` 聚合桶；
    - 必须恰好 1 个具体品种；
    - 具体 ticker 映射到决策 enum（NVDA/TSLA/... → `US_STOCK`；USD → `DXY`；CNY/EUR/JPY → `FX`）。
- `backend/src_python/engine/ai_worker.py`
  - `_presanitize_for_schema` 的 target enum 补齐 `XAG/COPPER/BRENT/US_BOND/CN_BOND`。
  - target 归一为 `NONE` 后，用原文调 `resolve_specific_one`；命中则写 `target_asset` + `asset_route=alias_fallback`。
  - 批次循环 / Doubao 循环把 `content_map` 原文传入 `_presanitize_for_schema`。
  - provenance 写库时保留 `alias_fallback`，不被 `target_ok` 覆盖。
  - **没有清掉 `analysis_degraded`**：模型当时是对 `NONE` 做的分析，回退只补标的，不把 HOLD 硬变成可交易信号。
