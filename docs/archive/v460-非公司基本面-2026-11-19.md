# v460 · 非公司标的终于有基本面读数（2026-11-19）

## 一句话

以前只有美股/A股/港股有「基本面」这一票，黄金、原油、美元、外汇、加密被记成
「非公司标的，N/A」，`decision_guard` 里那 0.08 的权重直接让出后归一化 ——
这些品种的方向**完全没有可复现的基本面依据**，只剩新闻情绪 + 价格派生因子。
这一版给 7 个品种各接一条可审计的基本面分量，同时把 prompt 里 COT 那 168 行
压成一行结论。

| 品种 | 改动前 | 决策链里的实际表现 |
|---|---|---|
| 美股 NVDA/TSLA… | 有（估值分位 + 盈利修正 + 同业 + 宏观倾斜） | 7 因子全可得 |
| A股 / 港股 | 有（v455 补的 PB/PE 分位） | 7 因子全可得 |

| 美元 / 外汇 | **无** | 同上 |
| BTC / ETH | **无** | 同上 |
| 白银/铜/天然气 | **无，且确实没数据** | 保持 N/A（不装懂） |

一个容易误判的点：`XAUUSD`、`BTCUSDT`、`EURUSD` 这些代码会被
`asset_kinds.classify` 认成「美股 ticker」，于是老代码返回的是
**`no_data`（缺口）**而不是 N/A —— 复盘时看起来像「美股财报还没采到」，
其实是口径根本没有。这次一并修掉。

## 三、三个「不给分」的硬门槛（防自欺）

1. **分量不足 2 个，或独立数据族不足 2 个 → 不发分**（`reason='insufficient'`）。
   为什么加"数据族"这一层：实际利率的"水平"和"变化"是两个分量，但只有一条 FRED 序列，
   算两个独立证据等于自己给自己凑分。测试 `test_single_component_is_insufficient_not_a_score` 钉死。
2. **分位至少要 30 个观测**。周频序列（EIA/COT）每天只新增 1 个点，靠库里攒要半年；
   所以 feed 改成一次抓 **52 周**并把原始点放进 payload.history，分位当场可用 ——
   这是"同一次抓取的原始观测"，不是补造历史。
3. **说不清符号的一律不做**，明确写进 `gaps`：
   - SPDR 黄金 ETF 持仓（官网 CSV 本机 DNS/SSL 长期不可达）
   - WTI 基差/期限结构（本机无免费永续源）
   - OPEC+ 产量与配额（无免费稳定源）
   - BTC ETF 净流入（`SOSOVALUE_ETF_URL` 未配置）
   - 白银/铜/天然气：`unsupported`，返回 0 分是"中性"会被误读，所以直接判不可得

## 四、接线：三处改动，一处不能漏

| 位置 | 改动 | 为什么必须改 |
|---|---|---|
| `feeds/eia_feed.py` | 新增 `oil.us_crude_production` / `oil.refinery_inputs` / `oil.distillate_stocks`；产量/炼厂走 `/v2/seriesid/PET.<id>.W`（`stoc/wstk` 那条路由只有库存）；一次抓 52 周 | 库存是结果，产量/开工率才是供给端的主动变量 |
| `fundamental_factor.build()` | 最前面判断 `alt_fundamental.canonical()`，命中即走 alt；否则原来的路由不变 | `XAUUSD`/`BTCUSDT` 以前被当美股 ticker → `no_data`（假缺口） |
| `decision_guard._f_bits` | 增 `kind=='alt'` 分支，文案写「非公司基本面 XAU: real_yield=-0.66（…）」 | 不写就会套用「估值分位/盈利修正」的说法，复盘会把黄金的 −0.46 当成"PE 太贵" |
| `macro_context.render_prompt_block` | 新增 `_alt_fundamental_block()`（一行结论）+ `_cot_block()`（COT 168 项 → 只展开投机净头寸类） | prompt 里要"结论"不要"原始点位"；COT 一层占 prompt 1/4 |

|---|---|---|
| 美国原油产量 WCRFPUS2 | 14,032 | 千桶/日 |
| 炼厂原油投入 WCRRIUS2 | 16,918（chg −129） | 千桶/日 |

## 八、同日「干净起点」：为什么必须清掉旧账

问题不在于旧数据"难看"，而在于**口径不同**：v460 之前，黄金/原油/美元/外汇/加密在
`decision_guard` 里 fundamental 记 `available=False`、0.08 权重让出后归一化；v460 之后
这些品种真的占这 0.08。两套口径的决策混在一张表里，任何"基本面因子有没有用"的统计
（`decision_fundamental_snapshot`、`fundamental_shadow`、影子账本胜率）都会被前一段污染成
不可解释的结果。

做法沿用项目 v340 那次的既定流程（`backend/scripts/oneoff/reset_derived_epoch.py`，只删结论、不删事实）：

| 项 | 结果 |
|---|---|
| 清空表 | **106 张**，合计 **109,284 行**（决策/成交/持仓/订单/影子账本/基本面影子/技术信号/异动/归因/反思/权重历史/模拟盘） |
| 模拟盘 | `t2_account` 本金重置 **10,000**（cash 10,000 / equity 10,000 / realized 0），持仓、订单、成交全清 |
| 因果链 | 854 条定义保留，`weight` 重置 1.0、hit/miss 清零 |
| 备份 | `backend/runtime/backup/reset_20261119_0804.db`（1,007 MB，SQLite backup API 含 WAL，可整库回滚）；清单 `reset_manifest_20261119_0804.json` |
| 纪元 | `data_epoch` 第 3 条：`v460 干净起点（非公司基本面接通后）` |

**保留的原始事实（一条没动）**：新闻原文 28,715 · 事件 32,505 · 宏观快照 779,838 ·
外部指标 189,049 · K 线 346,485 · 日线 106,961 · 资金流 35,798 · COT 2,067 ·
因果链定义 854 · 财报 236/9 · 财经日历 1,340。

清理后实测 v460 分量照旧可用（宏观事实还在）：XAU −0.46 / WTI +0.06 / BTC −0.22。

> 注意：`data_epoch.started_at`（2026-11-19 08:04）之后才是新口径样本，
> 三把尺与 A/B 复盘统计都应以该时间切片，否则又会把旧账算进来。
