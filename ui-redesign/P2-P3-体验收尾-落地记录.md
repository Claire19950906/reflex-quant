## 一句话

## 背景与结论

对 `.shots/` 下首页 / 模拟盘 / 漏检 / 反思 / 发现 / 新闻流各档截图做了一轮评审，结论是：**不需要重设计**——卡片、配色、圆角已有统一组件基础，P0 降噪、P1 首页重构已落地；问题集中在信息顺序、参数可读性、导航入口和重复轮询，属于局部收尾。

## 改了什么

### 1. 导航补齐死页入口（P2）

`components/app-nav.tsx`

- 「更多 → 研究」分组补入两个此前只能敲 URL 进入的遗留跳转页：
  - `/causal-chains` 因果链
  - `/asset-graph` 资产图谱
- 其余遗留页（experiences / flows / journal / market-scanner / calendar）本身已重定向到统一入口，不再重复挂导航。

### 2. 首页事件流默认收起（P3）

`components/quant/event-bus.tsx`

- 默认状态从「展开全部」改为**收起限高态**，首屏只露前 20 条摘要；点右上「全部」才展开全量。
- 收起态条数常量 `VISIBLE_INITIAL` 从 500 降到 20；提示文案同步改为「首屏前 20 条摘要，共 N 条」。
- 紧凑模式 `compact` 默认仍为开。

### 3. 复盘 / 错误面板默认折叠（P3）

`components/quant/live-desk.tsx`

- 新增通用折叠容器 `CollapsibleSection`（标题行 + 展开/收起，`aria-expanded`）。
- 「复盘战绩」（ReviewOverview）、「错误归因」（ErrorTaxonomyPanel）两个诊断面板**默认折叠**，点开才展开；首屏让给账户结论与实时信号。

### 4. 模拟盘参数区补单位、破坏性操作分层（P2）

`components/replay/replay-panel.tsx`

- 裸数字输入框补常驻单位：
  - 每日新闻目标 → 「条」
  - 新闻时效 → 「秒」
  - TP1× / TP2× 止盈倍数 → 「×MFE」
  - 比例1 / 比例2 平仓占比 → 「占比」
  - 止损倍数 → 「×ATR」
- 「重置模拟盘」从普通描边按钮改为红色描边实心、文案标注「⚠ 重置模拟盘（清空）」，与日常开关 / 主操作拉开层级；`title` 提示「先自动备份，不可撤销」。

### 5. 残留小字号清零（P0 收尾）

- 全站残留 8/9/10px 硬编码字号统一升到 11px，复核结果 **0 处**。
- 涉及：`app/divergence`、`app/capabilities`、`app/attribution`、`app/counterfactual`、`positions-table`、`account-kpis`、`divergence-strip`、`main-views-band`、`data-channel-standards` 等。

### 6. 三处重复轮询合并为一份取数（P3）

新增 `components/quant/use-replay-positions.ts`

- 背景：AccountKpis / PositionsTable / PaperEquityCard 原本各自 `useEffect + setInterval` 打同一个 `GET /replay/positions`，首页一开就是 3 份并行轮询（60s / 60s / 120s + 15s 快轮询）。
- 做法：LiveDesk 顶层挂一份 hook，把 `{ data, err, loading }` 下发给三个卡片；卡片只做派生计算与渲染，不再各自发请求。
- 轮询策略合并：快照未就绪 15s 追一次，就绪后 60s 慢刷新；沿用 `usePollRefresh` 的 in-flight 守卫，慢接口不会一轮叠一轮。
- 改动文件：
  - `use-replay-positions.ts`（新）
  - `account-kpis.tsx`、`positions-table.tsx`、`paper-equity-card.tsx`：去掉自轮询，改读传入 `snapshot / err / loading`
  - `live-desk.tsx`：顶层调用 hook 并下发

### 7. 深色主题对齐（P2 收尾）

- 现状：`globals.css` 明暗两套 token 齐备，`useIsDark` 通过 `<html>.dark` 同步给 canvas 图表；问题在部分组件写死浅色底/深色字（zinc、`*-50` 纯色底），暗色下变成浅底浅字。
- 改动：
  - `paper-equity-card.tsx`：权益曲线/渐变/端点由写死 `#2f9e6b / #d94a43` 改用语义色 `var(--long) / var(--short)`，暗色随 token 自动提亮。
  - `policy-patches-panel.tsx`：补丁候选面板全部 zinc 结构色、彩色 chip/文本补 `dark:` 兜底（边框、卡片、输入框、状态徽标、兄弟决策规则区）。
  - `failure-clustering-panel.tsx`：红/绿趋势徽标补暗色兜底。
  - `draft-summary-banner.tsx`：清除确认按钮 hover 底色补暗色兜底。
- `/10 /15` 透明度色（`bg-amber-500/10` 等）明暗通用，未改动；canvas/K 线图表已有独立 `CHART_THEME.light/dark` 分支。

### 8. 动效时长收口为 CSS token（P3）

- 现状：组件内 81 处 `transition-colors` / 17 处 `transition-all` 等沿用 Tailwind 默认 150ms；另有两处例外硬编码时长（`stat-cards.tsx` 的 200ms、`causal-graph-panel.tsx` 内联 120ms ease-out），缓动曲线散落在 `.pulse-dot` 关键帧里。
- 改动（`globals.css` `@theme` + `:root`）：
  - 新增令牌：`--duration-fast: 120ms`、`--duration-base: 150ms`、`--duration-slow: 200ms`、`--ease-out: cubic-bezier(0.4,0,0.2,1)`；v4 自动生成 `duration-fast/base/slow`、`ease-out` 工具类。
  - `stat-cards.tsx`：`transition-all duration-200` → `transition-all duration-slow ease-out`。
  - `causal-graph-panel.tsx`：内联 `opacity 120ms ease-out` → `opacity var(--duration-fast) var(--ease-out)`。
  - `.pulse-dot`：缓动改引 `var(--ease-out)`，周期 1.8s 保持不变。
- 取舍：81 处 `transition-colors` 未逐一改写，默认 150ms 即 `--duration-base`，与令牌对齐；后续若要统一加 `ease-out` 可在 base 层统一挂。

### 9. 诊断面板展开态持久化（P3）

- 背景：`CollapsibleSection`（复盘战绩 / 错误归因）原本用本地 `useState`，刷新后回到默认折叠，用户每次都要重开。
- 改动（`live-desk.tsx`）：面板状态按标题存 `localStorage`（key 前缀 `trident-collapse:`，值 `1/0`）；初始读取缓存，无记录回退 `defaultOpen`；切换即写回；读写包 `try/catch`，隐私模式等存储不可用时仅保留本次会话状态。
- 未做持久化：事件流 `showAll` 属首屏降噪默认值，每次回到收起态；轮询节奏维持就绪前 15s / 就绪后 60s，带 in-flight 守卫，不回调 120s。
