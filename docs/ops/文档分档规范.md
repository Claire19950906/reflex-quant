# 文档分档规范（P2-5，2026-11-19）

## 目录划分

| 目录 | 放什么 | 示例 |
|---|---|---|
| 根 `*.md` | 现行规范、手册、长期方案、接口/数据口径 | `约定规范.md`、`Trading_API_对接文档.md`、`SECURITY_DEMO_MODE.md` |
| `docs/ops/` | 运维与工程台账：进程模型、迁移规范、接口盘点、容器化说明 | `进程模型清单-*.md`、`schema-迁移规范.md` |
| `docs/operations/` | 单次操作手册（重启、排空队列等） | `trident-engine-restart-and-queue-drain.md` |
| `docs/reports/` | 周期性日报 / 体检报告（按日期） | `analysis-daily-2026-11-19.md` |
| `docs/patches/` | 历史补丁文件 | `优化落地-*.patch` |
| `docs/archive/` | 已被取代的历史版本记录、日期快照（vNNN-*、带 2026- 日期） | `v476-*.md`、`*归因-2026-11-17.html` |

## 归档判据（移入 `docs/archive/`）

满足任一即归档：
1. 文件名以 `v数字-` 开头的版本快照；
2. 文件名带日期后缀（`2026-MM-DD`）的一次性记录/体检/成绩单；
3. 已被现行文档取代、仅留作回溯的方案/事故复盘。

**不归档**：版本号嵌在文件名中段但仍现行的方案（如 `策略版本赛马场-v476.md`、`系统优化规划v3.md`）；长期规范与手册。

## 引用规则

- 源码/前端注释里引用文档，优先写现行文档路径；引用历史快照时写 `docs/archive/<文件名>`。
- 归档移动文件后，需全仓搜原文件名，把源码/前端中的路径引用同步到 archive，避免断链。
- 文档之间按标题互引即可，不依赖相对路径；新台账以 `docs/ops/` 为准。

## CHANGELOG 分档

- `CHANGELOG.md` 保留**未发布 / 当前版本**的条目（发版口径见 `config._read_changelog_version`，只读首行版本号）。
- 旧版本明细属历史记录；积累到一定体量后，按版本区间切到 `docs/archive/changelog/`，根文件只留近 30 版。
- 2026-11-19 已切分：根文件 v463–v496（30 版）；v462 及更早 63 版归档到
  `docs/archive/changelog/CHANGELOG-archive-v463-and-earlier.md`。
- 切分后须复核：根文件首行版本号不变；根内 `./docs/...` 链接目标存在（已归档的 vNNN 文档链接改指 `docs/archive/`）。
- 禁止在 CHANGELOG 堆长期方案；长期方案进根 `*.md` 或 `docs/ops/`。
