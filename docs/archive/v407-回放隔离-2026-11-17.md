# v407 · 回放隔离：历史回放不许进绩效口径

> 用户指令：「当然需要个隔离，系统内任何一个角落都不得出现假数据编造的信息」。
> 本文记录这一版的四件事：把回放从绩效里隔离出去、封掉三处造数源、修掉两个让假数据复发的 bug、
> 把每日守卫从 7 类扩到 9 类。

## 一、问题：回放被当成绩效样本

`trident2` 的 `t2_sim_trades` 是**历史回放**（source=`news_replay` / `decision_replay`，2028–2030 条）：
拿历史新闻/决策重跑一遍，用真实 1m 行情结算。它的原 docstring 自己写着"这是 F12/F45/F59 的样本来源——
quick_sim_trades 只有 3 笔，撑不起统计"。

三个对外 feature 的实现都是同一模式：

```python
if len(paper) >= 阈值:          # 回放样本够多
    trades, source = paper, "t2_sim_trades(历史回放)"
else:
    trades, source = live, "quick_sim_trades(纸面实跑)"
```

问题不在"回放数据本身是假的"——行情和新闻都是真的；问题在**口径**：回放可以反复重跑、可以调参重选样本，
它的胜率/Sharpe 与真实成交不可比。把它当绩效，等于用一个能刷的样本池自证有效。

## 二、改法：两条管道彻底分开

| | 研究管道（回放） | 绩效管道（真实成交） |
|---|---|---|
| 表 | `t2_sim_trades` | `quick_sim_trades` |
| 读取入口 | `Context.replay_trades()` | `Context.live_trades()` |
| 用途 | 研究 / 复盘 / 调参 | 胜率、Sharpe、累计盈亏、置信度校准 |
| 口径 | 可以重跑、可以换样本 | 一笔就是一笔，不可再生 |
| 输出标记 | — | `value.data_class = "live"` |

具体改动：

- `trident2/context.py`：`paper_trades()` → `replay_trades()`；新增 `live_trades(limit=500)`
  （`quick_sim_trades WHERE settled=1 AND pnl_pct IS NOT NULL`）；新增 `replay_count()`
  （只报"被隔离了多少条"，用于样本不足时说明规模）。
- `features/health.py` F45（策略健康度）：删除回放优先分支，只读 `live_trades`；`<20` 笔返回 `no_data`，
  headline「真实成交仅 N 笔已结算」，notes 写「历史回放 M 条已隔离，不进入绩效口径」。
- `features/research.py` F12（PnL 归因）：同上，阈值 `MIN_TRAITS`，`evidence` 只列 `quick_sim_trades`/`kline_bars`。
- `features/trust.py` F59（置信度校准）：整段回放分支删除，只用 `ai_decisions` 里
  `evidence_confidence IS NOT NULL AND settled=1` 的真实决策；对错取 `is_correct`，缺失时用
  `forward_pnl × direction`。

生产库只读实测（2026-11-17）：

```
F45 no_data | 策略健康度：真实成交仅 3 笔已结算 | …历史回放 2030 条已隔离，不进入绩效口径
F12 no_data | PnL 归因：真实成交仅 3 笔 | …历史回放 2030 条已隔离，不进入归因
F59 no_data | 置信度校准：可用样本仅 5 条 | …历史回放 2030 条已隔离，不参与校准
```

**宁可写"样本不足"，也不拿回放凑数**——这就是隔离的落地形式。

## 四、两个让假数据复发的 bug

1. **`engine/ai_worker.py` 用 `0.0` 顶替缺失 confidence**
   `_evidence_confidence_pre = float(_guard_pre.get("confidence") or 0.0)` —— guard 没给 confidence 时写 0，
   而 `is_unavailable()` 只看 coverage，coverage>0 但 confidence 缺失就走"有值"分支，于是 F1 清了又长
   （实测 22:47 新增 4 条 `summary_only` 降级行）。改为：`confidence` 缺失/不可转数字 → `_conf_unavailable=True`，
   落库 NULL。
2. **`_now_sticky = _ts()` 类型错误**
   `_ts()` 返回字符串，却和 `_MAIN_STICKY["since"]`（float 0.0）相减；第一次 idx 为 None 时不比较，
   把字符串存进 since，下一批直接 `TypeError` 打断整个 `ai_worker` 主循环。改 `time.time()`。

修复后重启 engine，新产生的决策（id 11934–11941）里 `evidence_confidence=0 且 degraded` 为 **0 条**，
`evidence_confidence=NULL 且 degraded` 424 条（正确语义：没算过）。

## 七、口径约束（写进 AGENTS.md 0 号铁律）

1. 回放 = 研究样本，**永远不许进胜率/Sharpe/累计盈亏/校准**。
2. 绩效只有一个来源：`quick_sim_trades` 已结算真实成交。
3. 报"样本不足"时必须报出被隔离的回放条数，不许拿回放凑数。
4. 任何为了演示/页面好看的 `random` 造数代码都不得提交。
