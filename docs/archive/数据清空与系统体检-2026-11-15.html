四、顺手挖出的一个真 bug：慢涨检测对核心品种完全失效

BTC / ETH / XAU / WTI / DJI / IXIC 的慢涨慢跌，历史上一条都没进库已修
原因：fetch_prices() 只在 external_indicators 里找 close/price 这类 indicator； 这些品种名下挂了几十个指标（资金费率、OI、多空比…），判定"指标不明确"后直接 return []， 于是 [SKIP] indicator 不明确，慢涨检测被静默跳过。
修复：判定不明确时回退到 ohlcv_daily.close（31 个品种、8.6 万根日线）。实测恢复量：
BTC 2,625 根 → 1,144 个慢涨点
ETH 2,546 根 → 1,551 个
AAPL 6,020 根 → 1,543 个
MU 4,741 根 → 2,183 个
但阈值本身要改。现在全局用 |1d| ≥ 3%，实测各品种 3% 的发生率差 20 倍：
品种p50p90p953% 命中率建议阈值
BTC1.37%4.80%6.45%22.7%≈6.5%
ETH1.94%6.55%8.46%34.1%≈8.5%

3% 对 BTC 是"每 4 天一次"，对 XAU 是"两个月一次"——同一个阈值不可能同时正确。 建议改成 max(2%, 该品种近 250 日 |1d| 的 p95)，3日/5日按比例放大。
