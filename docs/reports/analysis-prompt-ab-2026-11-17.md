# prompt A/B 实验：把 0 分改成 ±0.05 有意义吗

> 实验时间 2026-11-17 06:45 · 模型 MiniMax-M3 · 24 条样本 × 2 臂 = 48 次调用
> 只跑不落库：不写 ai_decisions、不写 ai_call_stats、不改 prompt、不重启服务
> 复现：`python3 backend/scripts/analysis_prompt_ab.py --n 24 --horizon 60`

## 1. 先纠正我昨天的一个归因

我昨天说「474 条 score=0 是 prompt 教出来的」。今天按 `analysis_degraded` 拆开看，这个说法**不成立**：

| score=0 的来源 | 条数 | 占比 |
|---|---|---|
| `target_none`（骨架兜底） | 279 | 58.9% |
| `llm_empty`（模型空返回） | 72 | 15.2% |
| `summary_only`（只剩摘要） | 44 | 9.3% |
| `server_fallback`（服务端兜底） | 29 | 6.1% |
| **未降级、模型真给了 0** | **50** | **10.5%** |

也就是 **424/474（89.5%）的 0 分是降级路径写进去的**，不是模型判的 0。
真正跑完完整分析的 66 条里，仍有 50 条（**75.8%**）是 0 —— prompt 确实在压零，但它是次要原因。

**结论修正：主因是「降级即抹零」，不是提示词。**

## 2. 实验设计

同一批新闻正文、同一套输出契约（`action / sentiment_score / direction / direction_strength / reason`），只改一句：

- **臂 A（现状原文）**：拿不准方向时给 HOLD + sentiment_score=0，宁可观望不要瞎猜
- **臂 B（候选）**：即使结论是 HOLD 也必须给方向倾向，不确定用很小的非零值（±0.05~0.15），绝不用 0

事后结算：`kline_bars` 1 分钟收盘价，t0 = `created_at`，t1 = t0+60 分钟，缺口 10 分钟内取不到 bar 就跳过。

## 3. 结果

| 臂 | 解析成功 | 非零分 | 非零率 | 平均 \|score\| | 可结算 | 符号命中 |
|---|---|---|---|---|---|---|
| A（现状） | 24/24 | 7 | **29.2%** | 0.106 | 7 | **57.1%** |
| B（候选） | 24/24 | 24 | **100%** | 0.190 | 23 | **56.5%** |

- B 把 A 的 0 分改写成非零：**17 条**
- 线上（真实记录）是 0、实验给出非零：**21 条** → 这批方向是被降级路径抹掉的

## 4. 三个必须说清楚的结论

**① 非零率能拉到 100%，但方向正确率一点没涨：57.1% vs 56.5%。**

24 条样本里，符号命中率两臂都接近抛硬币（50%）。也就是说 `|score|` 小的那些 ±0.05，**只是让数据「看起来有方向」，并没有多出一点预测力**。昨天选择器回放里「B 档比 C 档差」的结论，在这里得到了独立复现。

**② 真正有信息的是大幅度分，但样本极少。**

实验里只有 `+0.72`（事后 +0.14%）、`+0.62`（事后 -0.19%）两条 |score|>0.5，一正一反对冲 —— 样本量根本不足以判断阈值。

**③ 所以「改 prompt」不是提升准确率的正确入口，正确入口是「别把方向抹成 0」。**

如果降级路径不再把 `suggested_action` 强压成 HOLD、不再把 score 清零，昨天统计出的那 **21 条被丢弃的方向**（60 分钟正确率 70%）本来就在账本里。

## 5. 建议（按性价比）

1. **先改降级路径，不改 prompt**：`compressed` 已经单列终态，但方向与分数仍被清零。让 `compressed` 行保留 `original_action` 与 `score`，只标记「不可下单」——这一步不需要模型配合，是纯代码。
2. **prompt 改动降为 B 方案**：只在压缩行上要求「必须给方向倾向」，且不外推到大模型全量，因为实测无收益。
3. **攒样本**：`forward_move_pct` 已从 43 补到 201 条（`analysis_settle.py --apply`），方向分非零的 20 条事后同向 13 条（**65.0%**）。到 60 条再谈阈值。

> 一句话：这次实验的产出不是「新 prompt 更好」，而是**证明了分数现在没有预测力，且 92% 的 0 分是记账造成的假象**。
