**瓶颈不在覆盖率，在深度和方向偏差。** 覆盖率上限只有 7%（不是 40%+），

## 二、三个真问题（附实测）

### 2.1 PE 陷阱：系统把"盈利最高点"读成"最便宜"

`PE = 收盘 ÷ TTM EPS`。周期股在盈利峰值时 EPS 最大 → PE 最小 → 历史分位 0% → 得分最高。
用 `equity_earnings_events` 的真实 EPS 拼 TTM 序列（每票 8 个点）实测：

| 票 | 近 8 期 TTM EPS | 盈利位置 | 波动度 | 现有得分 |
|---|---|---|---|---|
| MU | 4.01 → 75.28（18.8 倍） | **100%** | 4.08 | **0.931** |
| NVDA | 2.62 → 7.01（2.7 倍） | **100%** | 0.75 | **0.939** |
| GOOGL | 8.05 → 19.16 | 94% | 0.97 | 0.707 |
| AMZN | 5.53 → 8.50 | 98% | 0.33 | 0.236 |
| AAPL | 6.30 → 8.92 | 100% | **0.30** | 0.004 |
| COIN | 11.56 → −4.09 | 0% | 2.72 | −0.444 |
| CLSK | 1.38 → −2.05 | 0% | 5.98 | **−1.0** |

读法：**波动度低（AAPL 0.30 / AMZN 0.33）= 成长股，位置高不构成风险；
波动度高（MU 4.08）= 强周期，位置 100% 就是股价便宜的唯一原因。**
现在的代码不区分这两者，所以 MU 拿 0.93 —— 这是当前基本面层最贵的一个错。

### 2.2 亏损股只有一把尺子，且方向单一

COIN / RIOT / CLSK / MARA 的 PE 无意义（TTM 亏损 → 直接跳过），
`eq.pb` 历史序列不足（见 2.3），于是分数**只由 EPS 同比驱动**：

| 票 | EPS 同比 | 得分 | 缺什么 |
|---|---|---|---|
| CLSK | −248% | −1.0（饱和） | 无估值、无营收增速、无毛利率趋势 |
| COIN | −135% | −0.444 | 同上 |
| RIOT | −503% | −0.444 | 同上 |
| MARA | −214% | −0.444 | 同上 |

结果是四只不同基本面的公司挤在两个分数上。**亏得越多分越低**，把"周期底部亏损"
和"生意变差"读成同一件事。

### 2.3 数据"有宽度没历史"

| 层 | 现状 | 后果 |
|---|---|---|
| 美股三表 | 9 只 × 8 季，但 `eps_diluted` **全部 NULL**（靠 `equity_earnings_events` 拼） | 利润表口径与 EPS 序列不同源，交叉校验缺失 |
| A股/港股 | `cn_equity_fundamentals` **每票 1 行**（7 条），无历史 | 算不出同比分位、算不出盈利位置 |
| 净资产 | `total_equity` 仅 MU/MSTR/CLSK 有值，其余 6 只 NULL | PB 无法倒推 |
| `eq.pb` 快照 | 2026-11-17 单日，20 条/票（16 票共 312 行） | 距 60 样本门槛差约 3 个月 |
| `eq.mktcap` 快照 | 2026-10-03 → 11-17，**895 条/票（46 天）** | 拿去 ÷ 净资产可出 PB 序列，46 天样本，差 2 周 |

**结论：PB 分位不是"无解"，是"差 2 周样本 + 6 只净资产"。**

## 四、P0-1 的具体算法（可直接实现）

```
TTM 序列     = earnings_events 的 eps_actual 滚动 4 季求和，取近 8 点
盈利位置 pos  = (TTM_now − min) / (max − min)          # 0~1，1 = 历史最高
周期度 cyc    = (第2大 − 第2小) / |中位数|              # IQR 归一，抗单点异常
判型：
  cyc ≥ 1.5  → 强周期（MU 4.08 / CLSK 5.98 / COIN 2.72 / MARA 4.18 / RIOT 3.06）
  cyc <  1.5  → 平稳（AAPL 0.30 / AMZN 0.33 / NVDA 0.75 / GOOGL 0.97）
修正（只折半，不翻转，避免同一证据用两遍）：
  强周期 且 pos ≥ 0.80  → 估值分量 ×0.5，标 peak_earnings
  强周期 且 pos ≤ 0.20  → 估值分量 ×0.5，标 trough_earnings（亏损底部的"便宜"同样不可信）
  平稳                  → 不动
```

与 v406 的 `value_trap` / `growth_premium` 护栏并列，不叠加超过两次折半。

## 六、明确不做

- **不拿公司基本面硬套 XAU / WTI / BTC**（占 53% 决策）：那是宏观层的事，
  该加强的是 FRED / COT ↔ 品种的方向映射，不是给黄金编一份财报。
- **不做 DCF / EV-EBITDA**：缺现金流预测与折现假设，做出来是假精度，
  比"没有"更危险。
- **不做模糊名字匹配**：`Coles` ↔ `利亚零售` 这类误命中会污染决策，
  宁可解不出。
