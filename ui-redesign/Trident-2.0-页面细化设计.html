2.3 交互与自动刷新

  • 01事件流是唯一入口。任何卡片上的数字都应能点回它对应的事件或持仓，不做纯展示死数字。
  • 0260 秒统一心跳。KPI、事件流、反思概览同一节奏刷新；行情价格单独走推送，不触发整页重绘。
  • 03滚动位置保护。用户正在看历史事件时，新事件只累计到顶部提示条，不强行跳顶。
  • 04自动下单可见。下单请求发出、成交、拒单都进事件流；成功与失败使用同一行结构，只换状态色。
  • 05跨页联动。背离条 → 背离雷达；持仓行 → 归因；反思错误 → 反思系统；均带 query 参数定位。
加载中骨架屏保留真实行高，不出现整页 spinner。
空数据今日暂无事件，并给「查看昨日」入口。
断线价格与事件保留最后值，标题带显示数据延迟 Ns，恢复后自动补拉。
下单失败事件流红标 + 原因（余额/风控/接口），不弹模态框遮挡行情。
无权限只读账号隐藏下单按钮，其余照常。

2.4 验收口径

  • 01首屏 1440×900 内能同时看到：5 个 KPI、事件流至少 8 条、K 线、账户与持仓摘要。
  • 02从事件流点进任一事件，右栏详情在 1 次点击内出现，不需要跳页。
  • 03断线 30 秒内页面不白屏、不丢最后价格，延迟状态可见。
  • 04自动下单成交与失败都能在事件流中追到，且带时间、标的、数量、价格。

3.3 关键规则

  • 01不重绘。pivot 右 3 根确认后才出信号，界面明确写「滞后 3 根」，不把事后最优的点当成实时信号。
  • 02强度 ≠ 胜率。评分只放在信号行；胜率只放在校准/验证页，两个数字不在同一张卡上混用。
  • 03有效规则单独标记。只有通过样本外检验的规则显示「可执行」；其余仍可见，但不进执行层。
  • 04计划先于观点。任何信号详情必须同时有失效价与目标价，缺一不展示「买入/卖出」措辞。
无信号说明当前窗口与等级下没有成立信号，并给放宽等级按钮。
数据不足少于 150 根时显示「数据不足，无法计算」，不出空图。
样本不足校准表灰显，标注「样本 <20，不作结论」。
验证失败规则卡标红「未通过」，不隐藏。
台账为空给「同步最近 90 根」按钮与说明。

3.4 验收口径

  • 01切换标的后 2 秒内主图、信号、校准、共振全部更新，且选中信号自动落到最高分。
  • 02信号列表、右栏详情、图上标注三者指向同一条信号，不出现「列表选中 A、图上高亮 B」。
  • 03样本外页能直接读出：有效规则名称、检验样本数、命中率、扣费后每笔、结论。
  • 04台账每条可追到确认时间、入场、结算价、盈亏与是否命中。

4.3 交互与状态

  • 01默认看高影响。事件标记按影响强度分三档，弱事件默认折叠，避免图上长满点。
  • 02时间对齐优先。事件时间、K 线时间、价格反应时间三者同屏可比较；时区统一显示本地时间。
  • 03归因可反驳。每张归因卡都有「不准确」按钮，反馈写入反思样本，不直接改历史归因。
  • 04跨页入口。持仓行、事件流都能跳到这里，并带上 asset 与时间窗。
无事件显示「该窗口无归因事件」，不给空白图。
新闻延迟标记显示「待归因」，10 分钟后自动重试。
同题重复合并为一条，展开可看子报道。
来源故障标题带黄条 + 受影响源列表。
误归因标灰并保留，供反思统计，不删除。

4.4 验收口径

  • 01任选一根异动 K 线，能在 2 次点击内看到对应事件、来源与影响窗口。
  • 02同题多来源不会重复出现超过 1 条主事件。
  • 03归因卡上的跨标的反应可在同一屏核对，不需要跳页。
  • 04未解释波动比例可见，且能进入补归因流程。

08

通用状态、数据契约与落地顺序

所有页面共用同一套状态语言和刷新规则，避免每个页面对「加载中 / 没数据 / 出错」有不同解释。最后给出按优先级的落地顺序。

8.1 五种状态 每块都要定义

状态视觉文案与行为
加载中骨架屏，保持真实行高不显示「0」；超过 3 秒显示「仍在加载」而不是转圈。
空一句话 + 一个下一步「该窗口没有信号」+「放宽等级 / 查看昨日」，不放大空白插画。
出错局部红条，保留旧数据说明哪一块失败、影响什么；提供重试，不整页弹窗。
过期标题带黄点 + 最后更新时间数据超过阈值仍展示，但明确标「延迟 N 分钟」。
部分缺失缺失字段显示「—」不用 0 或空白代替；图例注明缺失原因。

8.3 落地顺序 先能看，再能查，最后能改

  • P0实时台 + 背离雷达。补齐首屏信息密度、有效背离条、样本外与台账；这两页决定每天的使用体验。
  • P1归因 + 反思。归因 K 线与错误分类是「看得懂」和「信得过」的基础；先做只读与下钻。
  • P2资金流 + 因果图谱。数据面更宽，先把大类流向与结论审计做出来，再补下钻与时间滑块。
  • P3写操作。下单、重跑、复核统一走确认与回执，不在首版开放批量操作。

8.4 一页纸检查清单

  • 01首屏是否能在 5 秒内回答这一页的核心问题？
  • 02每个数字是否带时间、基准或变化量？
  • 03选中态是否在三处（列表、图、详情）保持一致？
  • 04空、错、过期、部分缺失是否都有明确文案？
  • 05任一卡片能否点回它对应的原始事件或数据？
  • 06表格在 1180 宽下是否仍可读，不被压成逐字换行？
