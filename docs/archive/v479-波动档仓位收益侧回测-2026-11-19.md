# v479 · 2026-11-19 波动档调仓位：收益侧验证做完，结论是「不上线」

## 一句话

v414 只证明过「ATR 档位能识别波动」（风险侧），从没算过按它降仓之后净值是变好还是只是变小。
这次补完收益侧，并用**时间外滚动检验**复盘，四条结论：

1. **降回撤是真的**：16/16 个标的 MDD 变小；
2. **提升风险调整收益是假的**：离散三档只有 4/16 的 Calmar 高于满仓，符号翻转后 0/16；
3. **连续等风险版样本内像真的**（9/16，翻转后优于离散档 15/16），
   但**时间外滚动窗口胜率只有 26.5%（26/98）** —— 典型的样本内拟合；
4. 所以**本轮不改任何仓位计算**，只把这条证据固化进读数，防止以后被当成收益信号。

## 二、为什么必须补这一课

`technical_state.risk_profile()` 的日线档位（≥3.0% 高×0.5 / ≥1.5% 中×0.8 / <1.5% 低×1.0）
在 v414 只用「5 根内 |MAE|」验过风险侧（XAU 1d 3.54× / XAG 2.38× / BTC 1.73×）。
代码注释里本来就写着欠账：

> 这条只做资金风险对齐，**没有收益侧验证**

「高波动之后确实更颠」推不出「因为更颠所以该少拿」——这两件事在数学上不等价。

## 三、怎么验（严格因果）

脚本：`backend/scripts/risk_sizing_replay.py`（只读）

| 环节 | 做法 |
|---|---|
| 指标口径 | ATR14（Wilder）÷ 当日收盘 ×100，与 `technical_indicators.atr` / `market_state` 同源 |
| 因果约束 | t 日收盘算档位 → **t+1 日**生效，不引用任何未来数据 |
| 成本 | 单边 15bp，只在 \|Δsize\| 处收费（来回 30bp，与 `_COST_BPS` 同源） |
| 数据体检 | 重复收盘 ≤20%、主间隔 ≥50%；WTI 间隔 40.6% 不规整，剔除 |
| 现金收益 | 降仓腾出的现金按 0 收益（保守）→ 绝对收益必然低于满仓，只看风险调整口径 |

**四条对照**：A 满仓 1.00 / B 离散三档（线上就是这条）/ C 连续等风险
`clip(120日中位ATR%/当前ATR%,0.5,1.0)` / D 随机档位（打乱标签 200 次，保持同样降仓频率）。

**三项稳健性检验**：

- **随机对照 D**：保留同样降仓频率，只打乱时点。B 打不过 D，说明改善全来自"平均仓位更低"；
- **符号翻转**：收益整体取反、成本照收，检验结论是否只是"恰好赶上了上涨市"；
- **时间外**：前 70% 参照 / 后 30% 留出，再做**滚动窗口胜率**（每窗 250 根、步长 125 根）。

## 五、这轮最重要的方法论教训：翻转检验 ≠ 时间外检验

上一轮我先做了符号翻转，得到「C 优于 B 15/16、双向都成立」，看起来已经很硬。
但翻转只改变了**收益方向**，**时间段和波动结构完全没变** —— 它证明的是"对称性"，
证明不了"换个时间段还成立"。

真正做滚动留出后，同一个策略从 9/16 掉到胜率 26.5%。
**以后凡是要改仓位/敞口的结论，必须过「时间外滚动」这一关，只看翻转不算。**

## 七、下一步（要有耐心，不是加参数）

1. **攒时间**：本次美股只有 4 年、加密只有 200 根。时间外检验失效，一半原因是样本太短
   （4 年只够切出 5 个滚动窗）。等日线样本到 8~10 年再复验一遍。
2. **换目标函数**：Calmar 对短窗口极敏感（MSFT 留出段出现 A=0.03 导致比值 4.67 这种噪声值）。
   下次改用「每单位波动收益」或「MDD 改善的稳定性」，别只看比值。
3. **别碰阈值**：1.5%/3.0% 是 v414 的固定值，本轮没有搜索最优阈值。
   一旦开始搜，就必须配时间外检验，否则必然过拟合。
4. **商品/加密单独定阈值**：黄金白银 ATR% 常年 2~4%，固定 3% 等于常年半仓；
   要动就得先看各自分布的分位，而不是套用股票阈值。

## 八、局限（不粉饰）

1. **只做多 + 现金 0 收益**：这套回测不可能证明"降仓在熊市更好"，只能靠翻转诊断。
2. **不含止损**：只验仓位缩放，没模拟止损被打掉后的再入场，止损倍数是另一条待验的线。
3. **滚动窗长度固定 250 根**：换长度结论可能变，本轮没做敏感性分析。
4. **加密样本不足**：BTC/ETH/SOL 等 180~200 根且是单边下跌段，只进「样本不足」栏，不进结论。
