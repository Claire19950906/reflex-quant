## 3.5. 各品种盯盘优先级体系（v200 P2 知识库）

本节作为 LLM 分析的优先参考。三资产一句话总览：
- 黄金：10年期TIPS实际利率第一，美元指数第二
- 原油：库存+地缘航运第一，美元指数第二，OI 看资金拥挤

加密货币（BTC/ETH/SOL）盯盘指标优先级（最高→最低）：

【宏观层】（与黄金共用，最高优先级）
- 10年期TIPS实际收益率：下行→利好 BTC（无息资产）；上行→压制 BTC。熊市阶段 BTC 偏风险资产跟随纳指；强避险叙事时切换成"数字黄金"与黄金共振。
- 美元指数 DXY：走强→美元流动性收紧→利空加密；走弱→资金易流入风险资产。
- CME FedWatch 降息概率：降息预期=流动性宽松=利好加密估值。
- 纳指100（NDX）：多数时间 BTC 属风险资产、与科技股联动；强避险时才脱离纳指。

【加密衍生品特有指标】（永续合约专属，做加密最核心）
- OI 未平仓持仓量 ⭐核心（加密踩踏比原油黄金更剧烈）：
  * 价涨+OI 涨 → 新增杠杆多头进场，趋势有资金加持；持续走高代表多头拥挤，随时踩踏。
  * 价涨+OI 跌 → 空头平仓（空头回补），无新多头，反弹持续性差。
  * 价跌+OI 涨 → 新增空头开空，下跌动能强。
  * 价跌+OI 跌 → 多头止损爆仓去杠杆，恐慌抛盘，常见阶段性见底信号。
- 资金费率 Funding Rate（永续独有，阈值精修）：
  * 8h 费率 >0.03% 偏多拥挤；>0.1% 高度拥挤，反转概率大增。
  * 负费率绝对值 >0.03% 偏空拥挤，>0.1% 高度空头拥挤，反弹概率大。
  * 连续 3 根 8h 费率同号 → 单边情绪惯性，需警惕反转。
- 爆仓数据（多空清算量）：连续大单爆多头=加速下跌；集中爆空头=快速拉盘（杠杆踩踏效应远大于原油黄金）。
- BTC.D 市值占比：上涨→资金从山寨币回流 BTC、大盘避险；下跌→资金流出 BTC、山寨币行情启动。

【链上指标】（偏中长期，判断大周期）
- 交易所储备量（Exchange Reserve）：提币到冷钱包=长期持有者囤币=利好；大量转入交易所=准备卖出=利空。
- MVRV Z-score：判断周期高估/低估区间；高位高估易大级别回调。
- 稳定币总供应量：增长=场外增量资金进场；下降=资金离场。

【盘面技术指标】（短线交易，与原油黄金通用）
- RSI：重点看背离，单纯超买超卖在加密高波动里易钝化失效。
- MACD：动量判断，看红绿柱 + DIF/DEA 背离。
- VWAP：日内多空分水岭。
- ATR：用来设置止损；加密波动极大，ATR 用来控制仓位大小。

- 地缘冲突推升原油（供给风险）→ 通胀预期抬升 → 预期维持高利率 → 利空加密。
