## 2. 新增 API 端点

| Method | Path | 作用 |
|---|---|---|
| GET | `/api/connectivity/status` | 4 维度聚合状态 + 综合评分（0-100） |
| POST | `/api/connectivity/test-channel` | 单通道真实发送测试，返回 ok/info/latency |
| POST | `/api/connectivity/dispatch` | 全通道派发测试（支持 only/exclude） |
| POST | `/api/connectivity/reset-channel` | 重置某通道健康状态（清零连续失败） |

## 3. 通知通道统一层 (`notification_channels.py`)

与现有 `source_status.py` 同源设计：线程安全 RLock + 懒加载 + snapshot() 模式。

支持的 6 个通道：

| channel_id | kind | env vars | 测试场景 |
|---|---|---|---|
| `feishu` | webhook | `FEISHU_WEBHOOK_URL` | 已存在，飞书群 |
| `slack` | webhook | `SLACK_WEBHOOK_URL` ⭐新增 | 国际化团队常用 |
| `discord` | webhook | `DISCORD_WEBHOOK_URL` ⭐新增 | 海外 Discord 服务器 |
| `email` | smtp | `SMTP_*` | 已有，QQ 邮箱 SSL 465 |
| `wechat_sct` | wechat | `SERVERCHAN_SENDKEY` | 已有，微信公众号 |
| `wechat_pp` | wechat | `PUSHPLUS_TOKEN` | 已有，微信模板 |

**核心 API**:
- `register_known_channels()` — 启动时调用一次
- `send(channel_id, title, body)` → `(ok, info)` — 单发带健康计数
- `dispatch(title, body, only=None, exclude=None, min_status='any')` — 全通道并联
- `snapshot()` — 面板快照（与 source_status 同结构）
- `record_test(...)` / `reset_channel(...)` — 测试钩子

## 5. PWA 支持

- `manifest.json` — 可安装到手机/平板主屏（iOS Safari / Android Chrome）
- `sw.js` — service worker：
  - app shell `stale-while-revalidate`（首屏瞬开）
  - `/api/*` `network-first`（数据绝不能给旧值，5s 兜底）
  - SSE 流完全不拦截（实时性优先）
- 4 个 shortcuts：信号 / 模拟 / 反思 / 联通（长按 App 图标直达）

## 7. 配置指引

启用 Slack：
```bash
# Slack App → Incoming Webhooks → 添加到频道 → 复制 URL
export SLACK_WEBHOOK_URL="https://hooks.slack.com/services/T.../B.../xxx"
```

启用 Discord：
```bash
# 频道设置 → Integrations → Webhooks → New Webhook → 复制 URL
export DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/xxx/yyy"
```

启用后重启服务即可生效，无需改代码。
启动日志会显示 `[NOTIFY] feishu 未配置，跳过发送（…）` 只警告一次。
