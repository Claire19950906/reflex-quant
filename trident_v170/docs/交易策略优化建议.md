# 三大需求优化方案

> 基于当前系统架构（新闻驱动信号 → AI 分析 → 模拟盘建仓 → forward_tracker 持仓跟踪结算 → 复盘回灌）
> 状态图例：✅ 已实现 / 🟡 建议实现 / ⬜ 可选深化

---

## 需求 1：加强 AI 反思能力（现状：每日复盘 + 经验回灌）

**已实现：**
- ✅ 每日复盘（17 类失败 / 10 类成功归因，LLM 分析）
- ✅ 经验规则自动回灌 AI prompt（review_insights）
- ✅ 参考信号实时注入（品种/方向/阶段/入场时机胜率）
- ✅ 低效经验自动停用（样本≥10 且胜率<40%）

**建议深化（按价值排序）：**

| # | 方案 | 说明 | 工作量 |
|---|---|---|---|
| 1a 🟡 | **单笔实时反思** | 每笔结算后立即生成单笔复盘（为何赢/亏），写入经验候选；日复盘时汇总去重。把"每天反思一次"提升到"每笔反思一次"，迭代快几十倍 | 中 |
| 1b 🟡 | **经验命中验证** | 每笔新交易结算时标记"是否遵守生效经验"，定期统计每条经验的遵守率 → 只回灌"被遵守且有效"的经验 | 中 |
| 1c ⬜ | **细粒度经验** | 经验按 品种×方向×事件类型 分组注入（如只给 XAU 空单注入 XAU 相关经验），减少 prompt 噪音 | 中 |
| 1d ⬜ | **决策快照回放** | 失败原因里"模型判断错误"占比最高（79/105）→ 针对这类做"当时我看到什么、为什么判断错"的回顾（decision_context 里有行情快照） | 中 |

## 需求 2：优化买入/卖出策略（卖出逻辑 + 新闻即时性）

**已实现：**
- ✅ **新闻时效门槛**（后台可调，秒级生效）：新闻发布超过阈值（默认 2700 秒）BUY/SELL 不再建仓，防追旧闻
- ✅ **SELL prompt 即时性规则**：利空+价格未反应→果断 SELL；已大跌→不追空；恐慌类→置信上调
- ✅ **BUY prompt 即时性规则**：利多+价格未反应→果断 BUY；已大涨→不追多（利好出尽警惕）

**买入侧问题（数据暴露）：**
- ⚠️ 做多胜率 53.4% < 做空 56.3%——买入信号质量偏低
- ⚠️ BTC 占交易 78%（167/215），做多被 BTC 震荡市追多拖累

**建议深化：**

| # | 方案 | 说明 | 工作量 |
|---|---|---|---|
| 2a 🟡 | **BUY 方向准入加严** | 做多胜率偏低 → BUY 最低分数要求比 SELL 高一档（如 BUY≥0.4 / SELL≥0.3），或 BUY 需趋势确认（market_confirmation=positive 或 trend bull）才准入 | 小 |
| 2b 🟡 | **信号新鲜度分级** | 新闻 0-15 分钟=新鲜(置信×1.0)、15-30=中等(×0.85)、30-45=偏旧(×0.7)，超 45 不交易——BUY/SELL 都按新鲜度加权，比硬门槛平滑 | 小 |
| 2c 🟡 | **品种×方向胜率参考** | 参考信号按 品种×方向 细分（如 BTC 做多 51% vs XAU 做空 62%），AI 对低胜率组合自动降置信 | 小 |
| 2d 🟡 | **SELL/BUY 不对称门槛** | 用统计结果做方向偏置：做空胜率高 → SELL 最低分要求低一档（更愿意做空）；做多低 → BUY 高一档 | 小 |
| 2e ⬜ | **反向新闻即时平仓**（跨需求）| 持仓期间同品种出现**反向新闻**（如 XAU 多单遇"美债急升"利空）→ 引擎分析到即标记持仓，forward_tracker 平仓 | 中 |

## 需求 3：优化止损和出场逻辑（确保抓住一波行情）

**现状问题：**
- 只有**到期结算**（默认 120 分钟）+ **移动止损**（策略参数 trailing_callback_rate，从最高点回撤 X%）
- 没有初始止损、没有保本锁定、移动止损固定百分比（高波动品种易被扫）

**建议方案（多层出场体系，按触发顺序）：**

```
入场
 ├─ ① 初始止损   entry ± ATR×2（波动自适应，防被正常波动扫掉）
 ├─ ② 保本止损   MFE≥0.5% 时止损移到入场价（先保本，再让利润奔跑）
 ├─ ③ 分级移动止损  盈利越深回撤容忍越小
 │      +1% → 回撤 50% | +2% → 回撤 40% | +3% → 回撤 30%
 ├─ ④ 分级止盈   目标价1 → 止盈50% + 收紧止损；目标价2 → 再止盈30%；剩余20%让趋势跑
 ├─ ⑤ 市场反应窗口  入场 60 分钟内 MFE 未达阈值 → 新闻没驱动行情，提前离场
 ├─ ⑥ 冲高回落止盈  快速冲高（<30 分钟到 +0.5%）后回落超 50% → 主升段走完，止盈
 └─ ⑦ 到期兜底  以上都没触发 → 120 分钟到期结算
```

**止盈目标价怎么定（不用固定值）：**
- 推荐：**历史 MFE 统计**做动态目标——从已结算数据算"同品种×事件强度"的平均 MFE（如 XAU 强催化新闻平均 MFE 1.2% → 目标1=0.7%、目标2=1.2%），无需改 AI prompt
- 进阶（后期）：AI 输出 `expected_move_pct`（预期波动幅度），目标 = 预期×系数——需要 prompt + DB 加字段

| # | 方案 | 关键参数（默认建议） | 工作量 |
|---|---|---|---|
| 3a 🟡 | **ATR 初始止损** | `stop_loss_atr_mult=2.0`（用 decision_context 快照的 atr_pct）| 中 |
| 3b 🟡 | **保本止损** | `break_even_pct=0.5%`（MFE 达 0.5% 后止损移到成本价）| 小 |
| 3c 🟡 | **分级移动止损** | `trail_tiers=[{1%, 50%}, {2%, 40%}, {3%, 30%}]`（替代单一回撤率）| 中 |
| 3d 🟡 | **分级止盈** | 历史 MFE 动态目标 + `tp1_ratio=50%` / `tp2_ratio=30%` | 中 |
| 3e 🟡 | **市场反应窗口退出** | `exit_window_minutes=60` + `window_min_mfe=0.3%` | 中 |
| 3f 🟡 | **冲高回落止盈** | `fast_peak_pct=0.5%`（30 分钟内）+ `pullback_ratio=50%` | 中 |
| 3g ⬜ | **反向新闻平仓**（同 2e）| 引擎分析反向新闻 → 标记持仓 → 平仓 | 中 |

**参数管理**：全部放进 `paper_trading_settings`（同"新闻时效"模式），后台可调、实时生效。

## 实施路线建议

| 阶段 | 内容 | 收益 |
|---|---|---|
| **P0（已做）** | 新闻时效门槛 + BUY/SELL 即时性 prompt | 立即消除追旧闻 |
| **P1（推荐下一步）** | 3b 保本止损 + 3a ATR 止损 + 3c 分级移动止损（止损体系）| 亏损单不裸奔、先保本 |
| **P2** | 3d 分级止盈（历史 MFE 动态目标）+ 3e 市场反应窗口 + 3f 冲高回落 | 抓主升段、锁利润 |
| **P3** | 2a BUY 准入加严 + 2d 不对称门槛 + 2b 新鲜度分级（买卖质量）| 买入信号质量提升 |
| **P4** | 1a 单笔反思 + 1b 经验命中验证 | 反思频率质变 |
| **P5** | 2e/3g 反向新闻平仓 | 事件驱动闭环 |

> 每阶段改动都可独立上线、后台可调、可回退；不影响现有逻辑（新参数有默认值，不带参数时行为不变）。
