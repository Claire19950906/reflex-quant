## 三、回滚

改动全部是组件内的 className / 文案替换，没有跨文件依赖：

```bash
cd frontend
git checkout -- components/ui/data-state.tsx            # 单文件回退
git diff --stat                                          # 看全部受影响文件
# 字号替换是机械替换，若要整体回退：
git checkout -- $(git diff --name-only -- 'app' 'components')
```

回退后需要重新构建（生产产物在 `.next-prod`）：

```bash
NEXT_DIST_DIR=.next-prod npx next build
NEXT_DIST_DIR=.next-prod npx next start --port 3030
```
