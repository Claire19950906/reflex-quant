# v489 · A股/港股多期历史：从「一期主要指标」到 16 期趋势（2026-11-19）

> 一句话：东财接口本来就返回 16 期，旧代码只取了第一行；这次把 16 期全解析、全落库，
> 并顺手修掉港股「把三季报累计数当 TTM」的旧 bug。方向分公式没动，只加读数。

---

## 一、起点：不是数据源没有，是我们只取了第一行

v488 体检时 A股/港股是 9 行 / 8 只，除 00700.HK 外每只只有 2026-09-30 一期：

```
cn_equity_fundamentals: 9 行
00700.HK: 2026-09-30 + 2026-06-30
其余 7 只: 仅 2026-09-30
```

但 `_em(...)` 请求的是 `pageSize=16`，接口实际返回 16 期（约 4 年）。
旧 `parse_a_share` / `parse_hk` 只读 `rows[0]`，`persist` 只写最新一期，
`read_one` 只读最新一期 —— 数据在手里，被代码丢掉了。

## 二、顺手挖出的第二个 bug：港股累计口径被当成 TTM

港股 `OPERATE_INCOME` / `HOLDER_PROFIT` 是**年内累计**（Q3 = 9 个月），
`EPS_TTM` 才是真 TTM。旧 `parse_hk` 直接把 `OPERATE_INCOME` 当 `revenue_ttm`：

| 00700.HK 2026Q3 | 旧读数 | 正确 TTM | 差 |
|---|---|---|---|
| 营收 | 608.579 十亿 | **802.950 十亿** | 少算 24% |
| 归母净利 | 177.727 十亿 | **235.987 十亿** | 少算 25% |

修法与 A股一致：`本期累计 + 上一年年报 − 去年同类型累计`。
同时修了「港股报告类型带年份前缀」—— `2026年三季报` 与 `2025年三季报` 字符串不相等，
旧匹配找不到去年同季；改为按季度数（1/2/3/4）匹配。

## 三、实现

| 位置 | 改动 |
|---|---|
| `cn_fundamentals.parse_a_share_history` | 每一期都用「该期及更早的行」还原 TTM，不用未来年报回填过去 |
| `cn_fundamentals.parse_hk_history` | 逐期保留；营收/净利走 `_hk_ttm`，EPS 用接口给的 `EPS_TTM` |
| `cn_fundamentals.fetch_history` | 一次抓取返回 `{records, latest, count}`；`fetch_one` 保留为兼容入口 |
| `cn_fundamentals.persist_history` | 按 `(ticker, market, report_date)` 逐期 upsert；历史期无价格，不写假估值快照 |
| `cn_fundamentals.read_history` | 零网络读多期，按报告期倒序 |
| `cn_fundamentals.load` | 抓一次写 16 期，不只写最新 |
| `cron_equity_fundamentals.py` | 两处 A/H 抓取改为 `fetch_history` + `persist_history` |
| `cn_depth.py`（新增） | TTM 同比、毛利率Δ、ROEΔ、盈利位置、资产负债率、护栏、缺口 |

`cn_depth` 的口径：
- 同比只跟「上一年同一报告期」比，Q3 对 Q3；缺去年同季就 None，不拿相邻季凑；
- 盈利位置 `(now − min)/(max − min)`，需 ≥8 个 TTM 净利点，否则不下结论；
- 只判差：TTM 营收 ≤−10%、净利 ≤−20%、毛利率 ≤−2pp、ROE ≤−3pp、资产负债率 ≥0.85；
- 盈利位置高**不**打空头标签（成长股可以一直在高位），只放进 `earnings_zone`。

**这不是停机 backlog 重放**：回填的是已公布财报的季度序列，每期都用该期及更早的数据还原 TTM，
不用未来年报回填过去，也不补停机期间堆积的实时行情。

读法举例：
- **东山精密 / 新易盛**：TTM 营收翻倍/近翻倍，盈利位置在历史最高 —— 是景气高位，不是"便宜"；
- **翠微股份**：营收 −42%、盈利位置 0%，毛利率 +14.76pp 是收缩低毛利业务的结果，不是改善；
- **中科飞测**：营收 +39% 但毛利率 −3.63pp、净利转负 —— 增收不增利；
- **腾讯**：修正后 TTM 营收 803 十亿、净利 236 十亿，增速 +10%，位置 100%。
