# v490 · 判断能力对市场：基准层与测试口

> 一句话：**命中率不是能力。** 这套东西只干一件事 —— 把"对市场准不准"换成三个必须一起读的数，并且做到"数据还没进来也能看出什么时候能测"。

## 1. 为什么原来的读法一定误判

2026-11-04→11-19 这段行情：BTC −18.7%、ETH −21.9%、SOL −20.2%、WTI −14.2%、XAU −7.3%。

同期影子层（4h 真值）成绩单：

| 口径 | 值 |
|---|---|
| 裸方向命中 | 56.7%（n=61） |
| 其中 SELL | 80.6%（29/36） |
| 其中 BUY | 20.8%（5/24） |
| **同批样本「无脑做空」基线** | **62.9%** |
| **同批样本「同配比盲选」基线** | 62.6% |

结论：**裸命中率比一个没有判断力的策略还低 6 个点。** 那 56.7% 是行情给的空头红利，不是能力。

更早的大样本（10-11→11-09，n=1570 因果链）也是同一个故事：S3 49.2%，拆开 UP 37.1%(824) / DOWN 62.6%(746)，两类平均 ≈ **49.9% = 抛硬币**。

所以：**只看命中率，单边行情里人人都是股神。**

## 2. 三个口径（必须一起看）

| 口径 | 定义 | 回答什么 | 误读风险 |
|---|---|---|---|
| 裸命中 | `Σhit / n` | 现状，仅参考 | 单边行情白送 |
| 市场基线 | 同一批样本里：always-SELL / always-BUY / 同配比盲选 | 这段行情是不是白送的 | 只能说"不是白送"，说不出"剩多少" |
| **平衡准确率 BA** | `(P(喊BUY\|真涨) + P(喊SELL\|真跌)) / 2` | **有没有方向判别力** | 单方向系统恒为 50（见下） |
| 净期望 | `mean(方向符号×涨跌幅)×100 − fee_bps` | 判对方向到底赚不赚钱 | 忽略成本就会高估 |

### 为什么还要一个 BA'（按喊的方向算）

**只喊一个方向的系统，BA 恒等于 50** —— 全喊 SELL 时 `P(喊BUY|真涨)=0`、`P(喊SELL|真跌)=1`，平均正好 50，无论它对错。这是正确定义（它确实没有"区分涨跌"的能力），但会把两件事混在一起：

- 全喊 SELL、行情 65% 在跌 → BA=50、BA'=65：**beta（白送）**
- 全喊 SELL、行情只有 35% 在跌 → BA=50、BA'=35：**反指（翻符号可能就赚）**

所以判定层：**BA 判"有没有判别力"，BA' 判"是不是反着来"。**

## 3. 判定规则（永不 FAIL）

| 条件 | 结论码 | 含义 |
|---|---|---|
| n=0 | `empty` | 还没样本；若池内方向决策也为 0，会直接说"先修产出" |
| n<gate 或单边真值 | `thin` | 样本不足，只报区间 |
| BA'<45 | `inverted` | 系统性反指，先查方向符号 |
| BA≥55 且区间下界>50 | `edge` | 有判别力（若净期望为负会额外警告成本） |
| BA≥55 但区间压不住 50 | `marginal` | 方向可能对，证据不够 |
| BA≈50 但裸命中偏离 50 超过 5pt | `beta` | 命中率高是行情/配比白送 |
| 其余 | `flat` | 贴抛硬币 |

固定参数：`gate=200`、`margin=5pt`、`fee=12bps/往返`（都在模块顶部常量，改即改口径）。

## 5. 记分卡新增的三项

| ID | 名称 | 毕业线 | gate | 说明 |
|---|---|---|---|---|
| S21 | 影子层裸方向命中 | 55% | 200 | 仅参考；旧口径 56.7% 的真相在 S22 |
| S22 | 影子层平衡准确率（去偏置） | 55%+区间下界>50 | 200 | **唯一能回答"有没有能力"的数**，区间用解析解 |

## 6. 留的"口"：数据进来后不用改逻辑

统计层与数据源完全解耦，三个 loader 吐同一种 `Outcome`：

| loader | 现状 | 用途 |
|---|---|---|
| `load_shadow_ledger(conn)` | 有表、现在 0 条 | 影子账本（闸门前方向 + 4h/24h 真值），主口径 |
| `load_shadow_reflections(conn)` | 有表、现在 0 条 | 反射层（direction_ok/wrong），交叉验证口径 |
| `load_json(path)` | **未接线** | 回测/模拟盘导出的 jsonl，字段：`asset / direction / move_pct`（可选 `entry_ts / horizon_min / confidence`） |

新数据源进来 = 加一个 loader，判定/区间/渲染一行都不用改。

## 7. 怎么验证"逻辑是通的"（不依赖真实数据）

```bash
python3 backend/src_python/judgment_benchmark.py --selftest   # 0.2 秒
python3 -m pytest backend/tests/test_judgment_benchmark.py -q  # 19 项，约 2 秒
```

自检用四个**答案已知**的合成世界：

| 世界 | 构造 | 必须判成 |
|---|---|---|
| coin | 方向随机 + 涨跌随机 | 无优势（BA≈50） |
| bias | 全喊 SELL + 65% 在跌 | **beta**（裸命中 67%，BA 恒 50） |
| skill | 喊 SELL 时 62% 真跌、喊 BUY 时 62% 真涨 | 有判别力（BA≈62） |
| anti | 全喊 SELL + 只有 35% 在跌 | **反指**（BA 恒 50，BA'≈35） |

外加 4 组契约测试（空库/缺表/未结算行/loader 过滤），保证"数据没进来不炸、不把 0 当成能力 0"。

`--market-fixture coin|bias|skill|anti` 可以在**不碰数据库**的情况下看完整报告长什么样。

## 8. 当前实测（2026-11-19 重置后）

```
已结算 n=0 / 门槛 200
产能: 近 24h 决策 15 条 / 带方向 4 条 / 池内可结算 3 条（0.1 条/小时）
      已结算 0/200，距可判定约 83 天
结论: 没有可结算样本（样本不足）
```

关键不是"没样本"，是**产能**：0.1 条池内方向决策/小时。按这个速度，光靠等永远等不到 n=200。要测出来，先得把方向产出提上去（HOLD 占比过高，或方向被闸门全挡）。

## 9. 已知边界（读结论前先认这三条）

1. **样本自相关**：同一根 K 线被多条决策共享时，n 不等于独立样本数；按品种/时段拆开看，别把 61 条当 61 个独立证据。
2. **成本假设**：默认往返 12bps。不同品种（币/油/金/股）差很多，换假设要改口径串，否则前后不可比。
3. **窗口效应**：4h 判错、24h 判对的样本确实存在（历史实测 4 条）。窗口不是越长越好，但**同一批比较必须同窗口**。
