# v472 · 2026-11-19 分歧度显式化：给每个分数配上"可信不可信"

## 一句话

同一个分数可能来自两种完全相反的世界：**全体轻微偏多**，或者**一半极多一半极空**。
以前这两种在库里长得一模一样，只能人工翻 7 条 evidence 才能分辨。现在每个品种直接输出
`dispersion / dispersion_level / confidence / bull_weight / bear_weight`，
并且**高分歧按可信度给 0.08 权重打折**。

## 一、怎么算

```
disp  = sqrt( Σ wᵢ (sᵢ − score)² / Σ wᵢ )     加权标准差，0 = 完全同向
level = 高 (≥0.60) / 中 (≥0.35) / 低
conf  = max(0, 1 − disp / 1.5)                 可信度，1 = 全体一致
```

- `bull_weight` / `bear_weight`：方向为正 / 为负的分量权重各占多少（看清"票从哪来"）；
- `decision_guard` 的 `fundamental` 权重改为 `0.08 × (0.6 + 0.4 × conf)`：
  **conf=1 → 满权重 0.08；conf=0 → 0.048**，下限 0.6 倍是因为"分歧大 ≠ 没信息"，
  不能直接清零（清零等于假装没读过）。
- `macro_context` 的提示词里每个品种后面带一句"分歧高/中/低"，模型讲结论时不会把加权平均当共识。

## 三、这张表最该读出的三件事

**1. 四个"高分歧"品种的分数几乎都不能当方向用**

- **USDJPY +0.03、分歧 0.89**：多空权重几乎对半（0.34 vs 0.30），分数 ≈ 0 是"打平"不是"中性偏多"；
- **UST −0.16、分歧 0.65**：美债 7 分量里多头权重 0.36（拍卖需求强、信用利差走阔利多）与空头 0.72（实际利率高企）对峙；
- **US2Y +0.46、分歧 0.71**：短端一致看多利率下行，但曲线/通胀项在拉反向；
- **BTC +0.07、分歧 0.64**：链上三条极多（权重 0.70）对 ETF 净赎回极空（0.56）—— 这正是 v468/v469 反复讲的形态。

**2. "低分歧"的高分才最可信**

ETH −0.66（可信 0.79）、XAU −0.55（0.78）、SPX −0.67（0.83）、CSI300 −0.57（0.84）：
这些品种所有分量都指同一个方向，**分数可以直接用**。

**3. ETH 的 1.12 是全表最"纯"的空头**

ETH 空头权重 1.12、多头 0，分歧仅 0.32 —— 没有任何一条分量替它说话。
这是本轮最干净的做空结构（虽然方向上"干净"不等于"该做"，还要看价格与结构因子）。

## 四、接口变化（下游要跟着改）

`alt_fundamental.build()` 返回新增 5 个字段，**所有分支都有**（含 unsupported / insufficient / error，
值为 `None`，下游不用 `hasattr` 判断）：

```json
{"dispersion": 0.643, "dispersion_level": "高", "confidence": 0.571,
 "bull_weight": 0.70, "bear_weight": 0.56}
```

`decision_guard` 的解释段会多一句：
「分量分歧度高（0.643，多头权重 0.7 / 空头权重 0.56，可信度 0.571）」。
