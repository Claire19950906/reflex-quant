# 金融1.0 全功能优化清单（2026-11-18 23:00 实测）

> 口径：所有数字都是本机真实库/真实日志读出来的（只读查询），不是估算。
> 样本边界：纸面成交 16 笔、已结算样本远低于 60，任何胜率/均值**不构成结论**，只用于找系统性偏差。
> 本文只回答「哪些功能还有优化空间」，不改代码。

## 0. 一句话结论

系统**工程底座已经不弱**（CI 闸门、假数据守卫、反思分层、端点基线都在跑），
真正的优化空间集中在三件事：**门卫产能、标的绑定、单笔期望值**。
其余都是"跑得更省、看得更清"的第二梯队问题。

## 2. 分功能清单

### 2.1 新闻采集（多源接入 15+）

**现状**：今日入库 3,000+ 条，sina_flash 1,073 / jin10 366 / wscn 282 / finnhub 120 / feishu_jin10 109 / 东财 106…
过滤率极高：sina 987/1,073（92%）、jin10 319/366（87%）、wscn 248/282（88%）。

| 可优化点 | 依据 | 影响 |
|---|---|---|
| 死源下线或降频 | yahoo GC=F 60m 511 次全失败、CL=F 488 次全失败、okx NVDA/AMZN/META 0%、coinglass_lsr 0%、ig 0% | 少 2,000+ 次/天无效请求，源健康面板不再噪声化 |
| 高失败源加自适应退避 | polygon 仅 23.8% 成功、finnhub 49.7%、okx XAU 48.2%（18,615 次/天） | XAU 是最常交易标的，一半采样失败直接影响决策 |

### 2.2 门卫 / 实时过滤（L1 关键词 + gate LLM + 规则判决）

**现状**：24h 6,618 次 gate 调用，平均 7.2s；失败 2,125 次（32.1%）。
分模型看：MiniMax-M2.7-highspeed 4,806 次/22.2% 失败、M3.1-Flash 760 次/**51.6%** 失败、
本地 qwen2.5:3b 634 次/**98.1%** 失败、minimax-peer 475 次/50.1% 失败。
gate_down 归档按小时：09 点 362、14 点 200、15 点 215、13 点 163 → **21 点后只剩 1 条**（说明 v449 规则判决已生效）。

| 可优化点 | 依据 | 影响 |
|---|---|---|
| 给失败调用补错误码 | 1,069 + 622 条失败记录 `error_code` 为空，无法归因 | 32% 失败到底是超时/鉴权/限流，现在答不出来 |

| 门卫批处理 + 指纹缓存 | 6,618 次/天 ≈ 每 13 秒一次，同事件多源重复 | 预计砍一半调用量 |

### 2.3 主分析 / 决策链

**现状**：469 次/天，平均 17.2s，失败率 0.9%——通道是健康的，问题在**内容**：
① 39.8% 决策没有标的；② 88.2% 的分数落库为 0.0；③ 236 条 `evidence_confidence=0.0` 与"0 号铁律"冲突（需核对是否 F1 残留）。

降级原因构成（3 天 752 条）：`target_none 380` > `llm_empty 135` > `asset_late_bound 122` > `summary_only 82` > `server_fallback 33`。

| 可优化点 | 依据 | 影响 |
|---|---|---|
| 标的绑定做成"两步 + 硬约束" | target_none 380 + asset_late_bound 122 = 502 条（67% 的降级） | HOLD 噪声预计 -35% ~ -40% |
| NONE 决策不落决策行 | 425 条无标决策仍进 ai_decisions 与前端 | 前端噪声、统计被稀释 |
| 门卫主品种硬约束扩到 sibling 聚合 | v451 只覆盖"门卫主品种属池内" | 副品种仍大量 NONE |
| 分数归一化改为"真实读数 + NULL" | 943 条 0.0 让 score 分档/闸门全部空转 | 闸门阈值第一次真正可调 |

优先级：**P0**（标的两项），分数口径 P1

### 2.4 交易执行与持有期（纸面成交）

**现状（16 笔全量）**：15 SELL / 1 BUY；持有期**全部 20 分钟**；
平均毛 -0.018%，平均成本 0.182%，**净 -0.33%/笔**；毛>0 6/12，净>0 3/16；
平均 MFE **0.183%**，最大 MFE 0.394%。

这是全系统最值钱的一条结论：**毛边际 ≈ 成本，20 分钟持有期下没有胜算**。

| 可优化点 | 依据 | 影响 |
|---|---|---|
| 开仓闸加"预期位移 > 2×成本" | MFE 均值 0.183% vs 成本 0.182% | 直接砍掉负期望单 |
| 持有期分档（20m / 60m / 240m）按事件类型 | 16 笔全 20 分钟，单档把 MFE 锁死 | 给趋势类事件留出发酵时间 |
| 成本口径按品种排序 | XAU/WTI 16~30bps，加密货币同档 | 优先做低成本品种 |
| 方向偏置检查 | 15 SELL:1 BUY，score 集中在 -0.3 | 排除 prompt/闸门的单边倾向 |

优先级：**P0**（这条比任何代码重构都重要）
