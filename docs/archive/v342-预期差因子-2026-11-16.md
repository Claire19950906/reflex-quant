# v342 · 预期差因子（surprise）

> 2026-11-16 · 分支 `v342-judgment-grain` · 纯增量

## 一、问题

`econ_calendar` 早就在存 `actual / forecast / previous`（表 `econ_events`），但判断链**从没读过**。

CPI / 非农这类事件的方向本质由「超预期幅度」决定：

- 超预期 0.1 → 可能已 price in
- 超预期 2.0 → 重新定价

而闸门只看到标题情绪，把两者当成同一件事。

## 二、关键取舍：只给"反方证据"，不给方向

同一个超预期，对资产的方向取决于指标与政策反应函数：

| 指标 | actual > forecast | 风险资产 |
|---|---|---|
| CPI / PPI / PCE | 加息预期升温 | 偏空 |
| 非农 / ADP | 紧缩预期 | 偏空 |
| 失业率 | 宽松预期 | 偏多 |
| PMI / 零售 / GDP | 风险偏好回升 | 偏多 |

把符号写死等于制造假精度。所以本模块**不新增方向权重**（`DIRECTIONAL_WEIGHTS` 一字未动），只做两件事：

1. 给出 `norm`（超预期幅度归一，-1..+1）
2. 当「预期差方向与新闻方向相反 且 |norm| ≥ 0.35」→ **方向分折减**（最多 −25%）并记一条矛盾

## 三、实现

**`surprise_factor.py`**
- `parse_number`：`2.5%` / `150K` / `1.2M` / `(1.3)` 负数 / `3.4万`；`N/A`、`—` → None
- `compute`：`deviation = actual − forecast`；归一尺度优先用 `|forecast − previous|`（"预期 vs 前值"的典型变化），退化到 `|forecast|×5%`，结果夹到 ±1
- `polarity(indicator, asset)`：只给表内已知指标；**不认识的指标 → None（不给意见）**
- `find_event`：只认窗口（默认 ±30 分钟）内、标题关键词命中的事件；命中多个取最近
- 取不到 actual/forecast → `available=False`，不猜

**闸门（`decision_guard.py`）**
- 读 `row["surprise"]`；冲突且幅度够 → `final_score × damp`，`pre_surprise_score` 保留原始分
- 结果新增 `surprise` / `pre_surprise_score`；矛盾里出现 `news_vs_surprise`
- 任何异常只留日志，不影响主判定

**生产接线（两处）**
- `engine/ai_worker.py`（真实落库前的闸门调用）：`enrich_by_news_id(conn, nid, asset)` → 注入 `"surprise"`
- `api_server._factor_result`（因子预览/详情）：查 `econ_events` 后注入

新增 13 条用例钉死：
- 解析各种单位/括号负数/N/A
- 归一按「预期 vs 前值」折算并夹到 ±1
- 极性表：CPI 对 BTC −1、失业率对 BTC +1、CPI 对 USD +1、未知指标 None、WTI 未登记 → None
- 事件匹配：窗口内命中、超窗口不挂、按 news_id 读 raw_news
- 冲突判定：CPI 超预期 + BUY = 冲突；低于预期 + BUY = 不冲突；无极性/HOLD 永不冲突
- 闸门：冲突且幅度够 → 分数变小且记 `news_vs_surprise`；幅度小或方向支持 → 分数不变；无预期差 → 完全不变

## 五、不变量

- `DIRECTIONAL_WEIGHTS` 未改，不重排任何方向权重
- 没有 `surprise` 字段时，闸门输出与之前逐位一致（`pre_surprise_score == final_score`）
- `econ_events` 只读，不写入、不改 schema

## 六、遗留

| 项 | 说明 |
|---|---|
| 极性表覆盖 | 目前登记 CPI/PPI/PCE/非农/ADP/失业率/PMI/零售/GDP；WTI、美债等未登记 → 不给意见（宁缺不猜） |
| 事件库覆盖 | `econ_events` 自身文档写明"40 天只有 26 个可交易事件"；覆盖率是下一个瓶颈 |
| 前端 | 决策详情页可加"预期差 / 原因"一栏，目前只在 API 与库里可读 |
| 阈值 | `|norm| ≥ 0.35` 与最大折减 25% 是经验值，应随样本积累用 `caliprate_gate` 校准 |
