# 前端零引用端点审计（2026-11-16）

> 起因：有人判断「零引用的端点大概都是垃圾」。这里用证据回答，而不是凭印象。
> 结论：**大部分不是垃圾，是「前端没接但功能仍在」的接口，删了会掉能力。**

## 1. 方法

`backend/scripts/orphan_endpoints.py`，两条证据缺一不敢下结论：

| 证据 | 怎么取 | 含义 |
|---|---|---|
| `code_refs` | 扫仓库（frontend / scripts / deploy / docs / tests / backend / dashboard / ui-redesign）**加上仓库外真正会调本机的地方**（`~/.trident/wrappers`、`~/.trident/scripts`、`~/Library/LaunchAgents`） | 有人写这个地址 = 有调用方 |
| `log_hits` | 扫 `~/.trident/log/*.log` 里的 `GET|POST /api/...` 访问行，动态段按前缀比 | 有人真的请求过 = 在用 |

三级结论：

- `alive` —— 日志里被访问过（**别动**）
- `wired` —— 没人访问但代码里有引用，可能是 cron / 脚本 / 按需调用（留着）
- `orphan` —— 两条都没有（**也只是「没证据在用」，不等于没价值**）

> 局限：日志只覆盖近期，不含坡上一整年的历史；外部合作方/手工 curl 不会留下仓库内引用。

## 2. 数字

- 前端零引用端点：**140 条**
- alive **9** / wired **31** / orphan **100**
- orphan 里：GET 59、POST 40、PUT 1

机器可读清单：`backend/reports/baseline/orphan_endpoints.json`

## 3. orphan 的成分（重点：它们不是空壳）

按命名空间（前 12）：v189 15, news 12, v190 8, v186 6, reflection 6, timeseries 5, review 5, kb 4, trading 4, v188 4, v187 4, reasoning 3

抽样看下来，三层东西混在一起：

### ① 运维/交易扳手（POST，40 条）—— 应急工具，删了等于扔掉恢复手段
例：`/api/external/ingest`、`/api/abnormal/backfill`、`/api/review/attributions/auto-review`、
`/api/news/mark-all-read`、`/api/admin/swing-writeback`、`/api/beliefs/revise-all`、
`/api/v186/*/run`（重算经验/门控/纸面反思）

### ② 历史版本号命名空间（38 条）—— **看着像垃圾，实际带真功能**
例：`/api/v190/exchange/mode/start|stop`、`/api/v190/exchange/credentials`（交易所启停/凭证）、
`/api/v189/backtest/archive|cleanup`（回测归档）、`/api/v189/coinglass/lsr/*`（多空比）、
`/api/v187/llm-stats/*`、`/api/v186/trade-reflections`

不是薄别名：`v190_exchange_stop_all` 64 行、`v201/trade-points` 62 行、
`v189/lsr/ranking` 48 行、`v190/exchange/audit` 31 行 —— 删掉就是删功能。

### ③ 只读数据接口（GET，其余）—— 给人工/分析用，前端没接
例：`/api/timeseries/*`（tick/ohlc/factors/news/winrate）、`/api/kb/*`（知识库查询/统计）、
`/api/news/eastmoney|blockbeats|qinghong`（数据源探针）、`/api/trading/manager/status|logs`

## 4. 结论与处置

- **不删**。理由是删它们换不来多少整洁（代码都在一个文件里，删了还得逐个验证），
  但会实打实掉功能：交易所启停、凭证管理、回测归档、运维补数据。
- 真正值得再走一遍的只有 **② 历史版本号那 38 条**：如果确认每条都有等价的「新版路径」，
  可以按「老路径转发到新路径」的方式合并，而不是直接删代码。这需要逐条比对新旧实现，
  属于下一批（P1 剩余 divergent 里也有同类）。
- 若后续确认某条外部也没人用：删之前先把
  `python3 backend/scripts/orphan_endpoints.py --verdict orphan` 再跑一次，看 `log_hits` 是否仍为 0。

## 5. 复跑

```
python3 backend/scripts/orphan_endpoints.py                 # 人看的表
python3 backend/scripts/orphan_endpoints.py --json          # 机器读
python3 backend/scripts/orphan_endpoints.py --verdict orphan # 只看候选
```
