# v473 · 2026-11-19 影子仓位按分歧度打折

## 一句话

分歧度不再只影响方向分（0.08 权重），现在也进**影子仓位乘数**：
同一个分数，"全体一致"给 1.0 倍，"吵成一团"只给 0.75 倍。
仍然只记账、不改实盘 —— 但这次记下来的东西，A/B 时能直接验证"打折到底对不对"。

## 一、改了什么

| | v472 之前 | v473 现在 |
|---|---|---|
| `sizing_multiplier(score, available)` | `1 + 0.20×score`，截 [0.80, 1.20] | 签名加 `confidence`：`(1 + 0.20×score) × (0.75 + 0.25×conf)`，截 [0.70, 1.20] |
| 公司侧路径 | — | `confidence=None` → **逐位不变**（先按 v456 口径截断，再判断是否打折） |
| 快照表 | 只有 `sizing_mult` | 新增 `dispersion` / `dispersion_level` / `confidence` 三列（幂等 ALTER） |

**为什么先截断再加权**：公司票没有分歧度字段，如果先打折再截断，`score=-2` 的老口径会从 0.80 变成 0.70，
这个"顺手改到的行为"没有任何依据。所以顺序是：先按 v456 截到 [0.80,1.20]，只有带了 confidence 才继续打折到 [0.70,1.20]。
v456 的 `test_sizing_multiplier_is_bounded` 就是被这条挡下来的（回归时立刻报错，说明测试在起作用）。

## 三、落库能看到什么

`decision_fundamental_snapshot` 新增三列，每行现在都能回答两个问题：

1. 这个仓位是按**共识**给的，还是按**吵架**给的？（`dispersion` / `dispersion_level`）
2. 打折打了多少、为什么？（`confidence` + `sizing_mult` + `components` JSON 全量）

公司票那三列是 `NULL`、乘数仍按 v456 口径 —— 审计时一眼能分开"公司基本面"和"非公司基本面"两条路径。

## 四、验证

`tests/test_shadow_dispersion_v473.py` 8 条：

1. 无 confidence 时与 v456 **逐位一致**（±1.0 极端边界都测）；
2. conf=1 时等于基准（不打折）；
3. 低可信度（0.41）必须真的压下来，且降幅 > 0.10；
4. 5×4 组合全部落在 [0.70, 1.20]；
5. 不可用 / 分数缺失 → 恒 1.0；
6. 快照正确落 `dispersion/level/confidence`，乘数 ≈0.8955；
7. 公司行三列为 NULL、乘数 1.12；
8. `components` JSON 里保留分歧度（可离线复算）。

全量回归 **289 passed, 1 warning**。
